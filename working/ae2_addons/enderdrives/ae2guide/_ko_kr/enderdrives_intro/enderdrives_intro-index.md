# EnderDrives!

EnderDrives는 아이템을 다른 방식으로 저장하는 데 중점을 둡니다. 각 드라이브에 설정한 주파수에 따라 드라이브끼리 연결됩니다. 주파수와 공유 범위가 같은 모든 드라이브는 제작한 플레이어와 관계없이 같은 내용물을 공유합니다. AE2 시스템 안이든, 다른 차원이든, 다른 플레이어의 시스템이든 내용물은 전역으로 동기화됩니다.

추가되는 블록과 아이템의 전체 목록은 다음 가이드 페이지에서 확인하세요.
