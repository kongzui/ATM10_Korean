# MEGA Cells

![MEGA Cells 로고](assets/logo.png)

## 소개

**MEGA Cells**는 Applied Energistics 2에 더 높은 등급의 저장소를 추가하는 애드온입니다. 용량은
**1M**부터 무려 **256M**까지이며, 더욱 전문적인 저장 셀과 관련 도구 같은 특별한 기능도 제공합니다.

유체가 필요합니다.
