# 고급 패턴 공급기 업그레이드

패턴과 업그레이드를 모두 옮기지 않고도 패턴 공급기를 업그레이드하는 Advanced AE 아이템입니다.

## 고급 패턴 공급기 업그레이드

<ItemImage id="advanced_ae:adv_pattern_provider_upgrade" scale="3"></ItemImage>

일반 AE 패턴 공급기와 Extended AE의 확장 패턴 공급기에 사용할 수 있습니다. 이 업그레이드를 사용하면
기존 슬롯 수를 그대로 유지한 고급 버전으로 바뀝니다. 따라서 일반 제공기를 확장 제공기로
업그레이드할 때 사용한 재료를 잃지 않습니다.

## 고급 패턴 공급기 용량 업그레이드

<ItemImage id="advanced_ae:adv_pattern_provider_capacity_upgrade" scale="3"></ItemImage>

용량 업그레이드는 일반 패턴 공급기를 패턴 슬롯 36개를 가진 고급 패턴 공급기로 바로
업그레이드합니다.
