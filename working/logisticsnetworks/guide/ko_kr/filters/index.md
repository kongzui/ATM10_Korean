# 필터

필터는 채널이 옮길 수 있는 자원을 정하는 가상 규칙이에요. 노드 화면 오른쪽의 3x2 필터 칸에서 여세요. [필터 및 업그레이드](../nodes/filters-upgrades.md)를 참고하세요.

필터가 없으면 유형이 맞는 모든 자원을 옮겨요. 필터를 추가하면 해당 규칙을 통과한 자원만 옮겨요.

필터 슬롯은 **채널별**이에요. 노드의 모든 채널이 독립된 필터 버튼 6개를 가지므로, 각 채널에서 서로 다른 6가지 필터 설정을 동시에 사용할 수 있어요.

## 송신과 수신

송신과 수신 모두 필터를 사용하지만 전송의 어느 쪽에 놓는지에 따라 역할이 달라요.

- **송신(내보내기)**: 연결된 블록에서 **무엇을 꺼낼지** 정해요. 필터를 통과한 자원만 꺼내 네트워크에 제공해요.
- **수신(받아오기)**: 연결된 블록에 **무엇을 받아들일지** 정해요. 네트워크에 자원이 많아도 수신 필터를 통과한 것만 받아요.

보통 양쪽에 필터를 써요. 송신 필터는 공급처에서 나갈 자원을, 수신 필터는 목적지에 들어올 자원을 정해요. 여러 아이템을 모아 둔 상자에서 송신 하나가 다양한 아이템을 꺼내고, 여러 수신이 각각 좁은 범위만 받아들이는 방식이 흔해요.

허용 목록 / 차단 목록, 하나라도 일치 / 모두 일치, 각 항목의 규칙 모두 송신·수신 구분을 따라요. 특히 재고는 "여유 수량 남기기"와 "목적지 수량 제한"이 다르므로 양쪽에서 의미가 달라져요.

## 허용 목록과 차단 목록

모든 필터에는 두 가지 모드가 있어요.

- **허용 목록**: 채널이 옮겨도 **되는** 자원의 목록이에요. 목록에 없으면 막아요.
- **차단 목록**: 채널이 옮기면 **안 되는** 자원의 목록이에요. 나머지는 통과해요.

노드의 필터 칸에서 가상 필터를 열어 모드를 바꾸세요.

## 하나라도 일치와 모두 일치

채널에 필터가 여러 개 있으면 패널 위의 **하나라도 / 모두** 버튼으로 조합 방식을 정해요.

- **하나라도 일치**: **하나 이상**의 필터가 허용하면 통과해요.
- **모두 일치**: **모든** 필터가 허용해야 통과해요.

자세한 설명은 [필터 및 업그레이드](../nodes/filters-upgrades.md#filters)를 참고하세요.

## 필터 유형

### 소형, 중형, 대형

소형, 중형, 대형 필터는 모두 같은 정확 일치 방식과 **45슬롯**의 항목 칸을 사용해요.

- 아이템 ID와 유체 ID가 정확히 일치하는지 검사해요.
- 아이템이나 유체 양동이를 항목 슬롯에 넣어 목록에 추가해요.
- 항목을 지우면 목록에서 제외돼요.
- 빈 항목 슬롯은 무시해요.

각 항목의 세부 설정 화면에서는 태그 일치, 전송량 덮어쓰기, 재고 기준값, NBT 규칙, 연결된 보관함의 슬롯 제한도 설정할 수 있어요.

### 모드

모드 필터는 설정한 모드 ID의 모든 아이템과 유체에 일치해요.

- `minecraft`, `create`, `mekanism`, `ae2` 같은 모드 ID를 지정하세요.
- 모드 필터 하나는 모드 하나에 일치해요.
- 여러 모드를 허용하려면 같은 채널에 모드 필터를 여러 개 넣고 **하나라도 일치**를 사용하세요.

### 정규식

정규식 필터는 제한된 정규식 문법으로 자원의 표시 이름을 검사하며 대소문자를 구분하지 않아요.

- 패턴의 최대 길이는 128자예요.
- 지원: 일반 문자, `.`, `[A-Z]` 같은 문자 클래스, `^`, `$`, 이스케이프한 문장 부호, 최상위 `|` 선택식.
- 미지원: 그룹, 전후방 탐색, 역참조, 인라인 플래그, 반복 연산자 `*`, `+`, `?`, `{...}`.
- 전체 이름에서 일치하는 부분을 찾으므로 `Iron`만으로도 `Iron Ingot`에 일치해요. `.*Iron.*`은 필요하지 않으며 거부돼요.
- 위험하거나 잘못된 패턴은 고칠 수 있도록 계속 보이지만 어떤 자원에도 일치하지 않아요.

자주 쓰는 예시예요.

| 패턴 | 일치 대상 |
|---------|---------|
| `Iron` | "Iron"이 포함된 이름 |
| `^Iron` | "Iron"으로 시작하는 이름 |
| `Ingot$` | "Ingot"으로 끝나는 이름 |
| `^Iron Ingot$` | 정확히 "Iron Ingot"인 이름 |
| `Iron|Gold` | "Iron" 또는 "Gold"가 포함된 이름 |
| `[IG]ron` | "Iron" 또는 "Gron" |

컴파일한 패턴은 전송 작업마다 재사용해요. 전송량이 많은 채널에서는 식의 범위를 좁게 잡으세요.

### 슬롯

슬롯 필터는 연결된 블록에서 채널이 읽거나 쓸 수 있는 슬롯 번호를 제한해요.

- `0`, `0-8`, `0-3,5`처럼 쉼표로 구분한 슬롯과 범위를 사용하세요.
- 유효한 슬롯 번호는 `0`부터 `53`까지예요.
- 송신에서는 목록에 있는 공급처 슬롯에서만 꺼내요.
- 수신에서는 목록에 있는 목적지 슬롯에만 넣어요.

## 항목 세부 설정

소형, 중형, 대형 필터의 각 슬롯은 단순한 아이템 검사보다 많은 일을 해요. 채워진 항목의 세부 설정을 열어 다음 규칙을 정하세요.

- **아이템 또는 #태그**: `minecraft:iron_ingot` 같은 정확한 ID나 `#c:ores` 같은 태그를 검사해요.
- **전송량**: 송신 측에서 이 항목을 한 번에 옮기는 수량을 덮어써요.
- **재고**: 송신에서는 여유 수량을 남기고, 수신에서는 목적지의 재고를 제한해요.
- **NBT**: 최대 6개의 활성 NBT/컴포넌트 규칙을 추가하거나 고급 설정용 원시 SNBT를 붙여넣어요.
- **슬롯**: 이 항목을 연결된 보관함의 특정 슬롯 번호로 제한해요.

전송량이나 재고를 `0`으로 두면 채널 설정을 따르거나 기준값 제한을 꺼요.

## 필터 복사와 붙여넣기

필터 화면에서 전체 설정을 복사하여 다른 필터에 붙여넣을 수 있어요. **Ctrl + C**로 복사하고 **Ctrl + V**로 붙여넣거나, 필터 상단 오른쪽의 **복사**·**붙여넣기** 아이콘을 누르세요. 마우스를 올리면 툴팁이 나오며, 복사한 내용이 없으면 붙여넣기 버튼이 어둡게 표시돼요.

이 클립보드는 현재 게임 세션에서만 유지돼요. 필터 아이템, 설정 파일, 운영체제 클립보드에는 저장되지 **않으며** 게임에서 나가면 지워져요. 렌치의 [복사/붙여넣기](../wrench/copy-paste.md) 클립보드와는 별개예요.

복사되는 내용은 필터 유형에 따라 달라요.

- **소형 / 중형 / 대형**: 모든 항목과 개별 규칙(아이템, 유체, 화학 물질 또는 `#tag`, 전송량과 재고 수량, 슬롯 대응, NBT의 엄격 설정·원시 SNBT·규칙·하나라도/모두 일치, 내구도, 마법 부여 여부), 필터의 허용/차단 목록 모드와 유형.
- **모드**: 허용/차단 목록 모드, 유형, 선택한 모드 ID.
- **정규식**: 허용/차단 목록 모드, 유형, 정규식 패턴, 일치 범위.

각 작업 결과는 짧은 메시지로 표시돼요. 원문 화면에서는 `Filter copied`, `Filter pasted` 등이 표시돼요.

알아두세요.

- 붙여넣기는 대상 필터를 **교체해요**. 일반 필터 슬롯을 먼저 비운 다음 클립보드로 채워요.
- 복사한 항목이 대상 용량보다 많으면 들어갈 만큼 채우고 일부만 복사됐다고 알려 줘요. 원문 메시지의 예시는 `Filter pasted: 6/8 slots copied`예요.
- 다른 유형의 필터에 붙여넣으면 호환되지 않는다는 안내와 함께 거부돼요. 예를 들어 일반 필터를 정규식 필터에 붙여넣을 수 없어요.
- 정규식이나 모드 ID 등의 입력란에 커서가 있으면 Ctrl + C와 Ctrl + V를 가로채지 않으므로 평소대로 글자를 편집할 수 있어요.

## 노드 사이의 필터 복사

노드 복사/붙여넣기, 같은 이름표의 노드 동기화, `.lnet` 저장/불러오기에서도 필터 설정이 복사돼요. 가상 필터를 비우려면 필터 메뉴 안의 항목을 지우세요.
