# 복사/붙여넣기 모드

렌치를 클립보드 도구로 사용하는 모드예요. 설정을 마친 노드를 렌치에 복사한 뒤 다른 노드 하나에 붙여넣거나, 같은 종류의 연결된 블록 전체에 한꺼번에 붙여넣어요. 실제 노드를 건드리지 않고 렌치에서 직접 설정 틀을 만들 수 있는 전용 편집 화면도 있어요.

**Shift + 마우스 휠**로 복사/붙여넣기로 전환하세요. HUD에서 모드를 확인할 수 있어요.

## 노드 복사하기

렌치로 **설정된 노드를 우클릭**하세요. 렌치 클립보드가 다음의 전체 설정 사본으로 바뀌어요.

- 9개 채널 전체의 상태, 모드, 유형, 면, 레드스톤, 분배, 우선순위, 전송량, 지연, 채널 이름.
- 모든 채널의 필터 칸에 있는 필터 설정.
- 노드에 설치된 모든 업그레이드.
- 노드 이름표.
- 노드가 소속된 네트워크.
- 노드의 표시 여부.

복사는 원본 노드에서 아무것도 제거하지 않아요. 클립보드는 렌치 아이템 자체에 저장되어 **게임을 다시 켜도 유지돼요**. 설정을 복사한 렌치를 상자에 넣고 몇 주 뒤에 꺼내도 사용할 수 있어요.

## 노드에 붙여넣기

렌치로 **Shift + 노드 우클릭**을 하세요. 렌치가 대상 노드에 클립보드를 적용하며, 성공하면 세 가지 작업이 이루어져요.

1. 대상 노드의 채널, 필터, 업그레이드를 클립보드 설정으로 덮어써요.
2. 대상에 필요한 부족한 업그레이드 아이템을 **보관함에서 자동으로 가져와요**. 렌치가 필요한 수량을 계산해요.
3. 붙여넣기 **전** 대상에 있던 교체 대상 아이템은 보관함으로 돌려줘요. 돌려받을 공간이 부족하면 붙여넣기를 시작하지 않으므로 아이템을 잃지 않아요.

### 붙여넣기가 실패하는 경우

- **아이템 부족** — 설정 틀에 필요한 업그레이드 아이템이 부족하면 중단하며 대상 노드는 바뀌지 않아요. 필요한 아이템을 준비하고 다시 시도하세요.
- **변경사항 없음** — 클립보드가 비어 있거나 대상과 정확히 같으면 바꿀 것이 없어요.

렌치가 결과를 짧은 채팅 메시지로 알려 줘요.

### 이름표도 함께 복사해요

붙여넣으면 대상에 **클립보드의 이름표가 유지돼요**. 대상이 즉시 원본의 이름표 그룹에 참가하므로, 나중에 같은 이름표의 노드 하나를 바꾸면 모두에게 적용돼요.

이름표를 옮기고 싶지 않으면 아래 편집기에서 이름표 입력란을 비운 뒤 붙여넣으세요.

## 연결된 블록에 일괄 붙여넣기

복사/붙여넣기 모드에서 **Ctrl + 노드 우클릭**을 하세요. 렌치가 해당 노드부터 **같은 종류의 연결된 블록**을 따라 탐색하며(최대 16,384개), 발견한 모든 노드에 클립보드를 붙여넣어요.

예를 들어 노드가 달린 화로 20개가 줄지어 있다면, 하나를 설정해서 복사한 뒤 20개 중 아무 노드나 Ctrl + 우클릭하세요. 나머지 19개가 한꺼번에 갱신돼요.

아이템 소모 조건은 노드마다 적용돼요. 붙여넣는 중 필요한 업그레이드 아이템이 부족해지면 남은 노드는 건너뛰고 적용한 수를 알려 줘요.

## 클립보드 편집기

실제 노드에서 복사하는 대신 렌치에서 직접 설정 틀을 만들 수 있어요.

복사/붙여넣기 모드에서 **허공을 우클릭**하세요. 앞에 블록이 없으면 클립보드 편집기가 열려요. 여기에서 다음 작업을 할 수 있어요.

- 실제 노드처럼 상태, 모드, 유형, 면, 레드스톤, 분배, 우선순위, 전송량, 지연, 이름 등 모든 채널 설정을 편집해요.
- 필터 슬롯에서 가상 필터 설정을 편집하거나 지워요.
- 업그레이드 아이템을 업그레이드 슬롯으로 끌어 놓아요.
- **지우기** 버튼으로 클립보드 전체를 비워요.

메뉴를 닫으면 렌치의 NBT에 변경사항이 저장되어 설정 틀이 유지돼요.

기준이 될 실제 노드를 먼저 만들지 않고 설정 틀을 한 번 설계한 뒤 새 블록에 대량 설치할 때 편리해요.
