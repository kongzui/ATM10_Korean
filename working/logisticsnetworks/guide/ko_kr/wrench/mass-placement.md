# 대량 설치 모드

반복되는 큰 설비를 한 번에 만드는 모드예요. 돌아다니며 블록을 표시한 뒤 설치 화면을 열면, 한 번의 클릭으로 모든 표시된 블록에 미리 설정한 노드를 설치해요.

**Shift + 마우스 휠**로 대량 설치로 전환하세요. HUD에 모드와 현재 선택 수가 표시돼요.

## 블록 선택하기

**블록을 우클릭**하면 렌치의 선택 목록에 추가돼요. 같은 블록을 다시 우클릭하면 제외돼요.

- 선택은 지우거나 설치할 때까지 렌치에 남아 있어요. 돌아다니며 새 청크를 불러온 뒤 돌아와도 유지돼요.
- 선택은 **차원별**로 관리돼요. 오버월드와 네더의 선택 목록이 별개이므로 다른 차원에 잘못 적용되지 않아요.
- **렌치당 최대 2048개**를 선택할 수 있어요. 한도를 넘으면 새 선택이 거부돼요.

## 연결된 블록 한꺼번에 선택하기

**Ctrl + 블록 우클릭**을 하면 연결된 **같은 종류의 블록**을 한꺼번에 선택해요. 긴 화로 줄, 상자로 된 저장 벽, 갈라지는 기계 줄을 하나씩 누를 필요가 없어요.

2048개 한도가 똑같이 적용돼요.

## 설치 메뉴

선택을 마친 뒤 **허공을 우클릭**하여 대량 설치 메뉴를 여세요. 앞에 블록이 없어야 해요. 메뉴에는 다음 정보가 표시돼요.

- 전체 선택 수.
- 유효한 선택 수. 여전히 존재하며 저장 기능이 있고 설치를 방해받지 않아 노드를 붙일 수 있는 블록이에요.
- 필요한 아이템. 물류 노드와 클립보드 설정 틀에 필요한 업그레이드예요.

메뉴의 **노드 설치** 버튼을 누르면 렌치가 다음 작업을 해요.

1. 보관함에서 필요한 아이템을 소모해요.
2. 유효한 선택마다 노드를 설치해요.
3. 새 노드마다 클립보드와 같은 채널, 필터, 업그레이드, 이름표, 네트워크를 적용해요.

유효하지 않은 선택은 아이템 소모 없이 건너뛰어요. 보관함 부족이나 청크 해제 등으로 도중에 실패한 선택은 결과를 알려 주므로 실제 설치한 수를 알 수 있어요.

## 설정 틀과 이름표 동기화

대량 설치한 모든 노드는 **이름표까지 포함해** 클립보드 설정 틀을 이어받아요. 처음부터 같은 이름표 그룹에 들어가므로 나중에 따로 설정하지 않아도 돼요.

일반적인 사용 순서예요.

1. [클립보드 편집기](copy-paste.md#clipboard-editor)에서 설정 틀을 만들거나 작동 중인 노드에서 복사하세요.
2. `furnace_row`처럼 이름표를 지정하세요.
3. 대량 설치로 전환하고 모든 대상 블록을 선택하세요.
4. 메뉴를 열고 노드 설치를 누르세요.

새로 생긴 모든 노드에 아홉 채널의 설정, 필터, 업그레이드, 같은 이름표가 준비돼 있어요. 나중에 하나를 편집하면 나머지에도 자동 반영돼요.

## 알아두기

- 클립보드 설정 틀이 없으면 대량 설치가 작동하지 않아요. 렌치가 비어 있으면 노드 설치 버튼이 비활성화되므로 먼저 복사하세요.
- 메뉴의 **지우기** 버튼은 아무것도 설치하지 않고 전체 선택 목록을 비워요.
- 모두 한 번에 설치할 필요는 없어요. 메뉴를 닫고 더 선택해도 렌치가 목록을 기억해요.
