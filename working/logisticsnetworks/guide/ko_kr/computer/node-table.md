# 노드 표

연결한 네트워크를 노드별로 보는 화면이에요. 소속된 모든 노드의 블록 종류와 위치를 보여 주며, 월드에서 노드를 찾거나 원격으로 설정하는 두 가지 작업 버튼이 있어요.

네트워크에 연결한 뒤 하위 시스템 버튼으로 여세요. 왼쪽 위의 **나가기**를 누르면 돌아가요.

## 표

![상자, 통, 통, 상자의 네 행을 보여 주는 노드 표](../computer/images/node-table.png)

각 행은 네트워크의 노드 하나이며, 열은 다음과 같아요.

- **장치** — 노드가 붙은 블록의 아이템 아이콘과 표시 이름(`Chest`, `Barrel`, `Furnace` 등)이에요.
- **위치** — 차원과 블록 좌표예요. 차원은 짧은 표기로 나타내요(`OVR` = 오버월드, `NTH` = 네더, `END` = 엔드, 사용자 정의 차원은 자체 약칭). 뒤에 `X, Y, Z` 좌표가 붙어요.
- **작업** — 각 행의 오른쪽에 아이콘 버튼 두 개가 있어요.

![노드 행 상세 — 오버월드 29,-60,70의 상자와 강조 표시·설정 버튼](../computer/images/node-row.png)

### 행별 작업

- **강조 표시**(램프 아이콘) — 월드에 있는 노드의 빛나는 윤곽선을 켜거나 꺼서 쉽게 찾도록 해요. 램프를 다시 누르거나 컴퓨터 화면을 닫을 때까지 유지돼요.
- **설정**(톱니바퀴 / 터미널 아이콘) — 어디에 있든 해당 노드의 전체 설정 화면을 **원격으로** 열어요. 채널이나 필터를 편집하려고 노드 옆에 갈 필요가 없어요.

## 이름표별 묶기

이름표가 있는 노드는 같은 이름표끼리 묶여요. 이름표는 그룹 제목 행으로 표시되며, 누르면 그룹 전체를 한 줄로 접고 다시 누르면 펼쳐요. 이름표가 없는 노드는 목록 아래에 개별 행으로 표시돼요.

접은 상태는 현재 세션 동안 유지돼요. 큰 네트워크에서는 작업 중인 그룹만 펼치고 나머지는 접으면 읽기 쉬워요.

이름표는 각 노드의 [상단 영역 → 이름표 설정](../nodes/header.md)에서 지정하거나, [렌치 → 복사/붙여넣기](../wrench/copy-paste.md)로 붙여넣을 때 자동 복사돼요.

## 일괄 표시 / 숨기기

노드 표 오른쪽 위에 두 버튼이 있어요.

- **표시** — 연결한 네트워크의 모든 노드를 **표시**해요. 렌치를 들지 않아도 모든 노드가 월드에 완전히 불투명하게 나타나요.
- **숨기기** — 연결한 네트워크의 모든 노드 표시를 **꺼요**. 렌치를 들 때만 반투명하게 나타나요.

노드별 표시 전환에 관한 설명은 [상단 영역 → 표시됨](../nodes/header.md)을 참고하세요.

## 페이지 이동

한 페이지에 일곱 행이 들어가요. 더 큰 네트워크에서는 마우스 휠로 페이지를 넘기세요.

## 알아두기

- 노드 표는 실시간으로 갱신돼요. 노드를 추가·제거하거나 이름표를 바꾸면 컴퓨터를 다시 열지 않아도 반영돼요.
- 원격 설정은 노드 앞에서 여는 것과 같은 전체 화면이에요. 필터, 업그레이드, 모든 채널을 다루며 변경사항도 같은 방식으로 적용돼요.
- 강조 윤곽선은 클라이언트에서만 표시되므로 서버의 다른 플레이어에게는 보이지 않아요.
