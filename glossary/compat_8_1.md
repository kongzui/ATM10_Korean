# 8.1 호환판 추가 용어

현재 8.1 영어 원문과 기존 프로젝트 번역을 기준으로 사용해요.

| 원문 | 번역 | 범위와 이유 |
|---|---|---|
| Nights of Nour | 누르의 밤 | Tombstone 이야기 제목. 고유명사 Nour는 음역해요. |
| Sarheed's Lamp | 사르히드의 램프 | Tombstone 아이템. 인명 Sarheed를 음역해요. |
| Ashkar | 아슈카르 | Tombstone 이야기 인명. 뜻을 추측하지 않고 음역해요. |
| Flying Carpet | 날아다니는 양탄자 | Tombstone 아이템·개체·설명에서 통일해요. |
| Silent Bond | 침묵의 결속 | 기존 이야기 제목의 표현을 효과명에도 사용해요. |
| Sewage Composter | 오물 처리기 | 확정된 Industrial Foregoing 블록명과 EMI 제목을 맞춰요. |
