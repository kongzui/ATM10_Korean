# 용어집

## 1. 용어집의 역할

- `AGENTS.md`는 번역 방법에 대한 필수 규칙을 담는다.
- 이 문서는 실제 영어 용어와 확정 한국어를 기록한다.
- 이후 모든 번역 작업은 번역 전에 이 문서를 확인한다.
- 새로 반복 사용될 용어가 확정되면 이 문서를 함께 갱신한다.
- 한 번만 등장하는 평범한 단어까지 모두 기록하지 않는다.

## 2. 용어 결정 우선순위

1. 현재 사용자의 직접 지시
2. 이 프로젝트에서 확정한 용어
3. 마인크래프트 공식 한국어와 널리 정착된 표현
4. 해당 모드의 기존 한국어 번역
5. 한국 커뮤니티에서 널리 사용하는 표현
6. 자연스러운 음역 또는 직역

기존 번역이 검색성과 일관성을 해치면 그대로 따르지 않는다.

## 3. 표기 종류와 일치 기준

- 공식 모드명은 원칙적으로 공식 영문 이름을 유지한다.
- 일반 카테고리명은 자연스러운 한국어로 번역한다.
- 아이템 기반 퀘스트 제목은 리소스팩의 확정 아이템 이름을 그대로 사용한다.
- 고유명사의 한글 음역이나 뜻 번역은 사용자가 별도로 확정한 경우에만 허용한다.
- 모드명, 아이템명과 퀘스트 제목의 표기가 충돌하면 이 용어집의 확정 표기를 기준으로 통일한다.
- 용어를 기록할 때 `공식 모드명`, `공통 카테고리명`, `아이템·블록명`, `기술 용어`, `예외적으로 번역하는 고유명사` 중 하나로 종류를 구분한다.

## 4. 확정 용어

| 영어 | 한국어 | 종류 | 적용 범위 | 상태 | 비고 |
|---|---|---|---|---|---|
| Upgrade | 업그레이드 | 기술 용어 | 전체 모드 공통 | 확정 | `기능`, `강화`, `개선 장치` 등으로 바꾸지 않음 |
| Advanced | 고급 | 기술 용어 | 아이템이나 업그레이드의 등급을 뜻할 때 | 확정 | 등급이 아닌 문맥은 별도 검토 |
| Pickup | 줍기 | 기술 용어 | `Pickup Upgrade` 계열 | 확정 | 다른 문맥에서는 적용 범위를 별도 결정 |
| Pickup Upgrade | 줍기 업그레이드 | 아이템·블록명 | Sophisticated Backpacks 및 관련 모드 | 확정 | `[기능명] 업그레이드` 형식 사용 |
| Advanced Pickup Upgrade | 고급 줍기 업그레이드 | 아이템·블록명 | Sophisticated Backpacks 및 관련 모드 | 확정 | `고급 줍기 기능`은 사용하지 않음 |

## 5. 보류 용어

아직 확정하지 않은 고유명사나 전문용어는 임의로 번역하지 않고 아래 표에 기록한다.

| 영어 원문 | 후보 번역 | 등장 모드와 문맥 | 보류 이유 |
|---|---|---|---|

## 6. 용어 추가 및 변경 규칙

- 여러 파일이나 모드에서 반복 사용될 용어만 추가한다.
- `Pickup`처럼 문맥에 따라 번역이 달라질 수 있는 용어는 적용 범위를 반드시 기록한다.
- 새 용어를 확정할 때 용어 결정 우선순위와 기존 확정 용어를 먼저 확인한다.
- 확정 용어를 변경할 때는 기존 사용 위치를 찾아 함께 교정하고, 변경 이유와 적용 범위를 비고에 기록한다.
- 문맥상 예외가 필요하면 기본 용어를 바꾸지 말고 예외 사유와 적용 범위를 기록한다.
