# 용어집

## 1. 용어집의 역할

- `AGENTS.md`는 번역 방법에 대한 필수 규칙을 담는다.
- 이 문서는 실제 영어 용어와 확정 한국어를 기록한다.
- 이후 모든 번역 작업은 번역 전에 이 문서를 확인한다.
- 새로 반복 사용될 용어가 확정되면 이 문서를 함께 갱신한다.
- 한 번만 등장하는 평범한 단어까지 모두 기록하지 않는다.

## 2. 용어 결정 기준

목표는 한국 플레이어가 바닐라 화면, 다른 모드와 커뮤니티에서 보던 말과 어긋나지 않게 하는 것이다.
통일은 검색되는 이름에 엄격하게, 문장에는 유연하게 적용한다.

1. 사용자의 직접 지시와 이 문서의 확정 용어가 가장 우선한다.
2. **이름**(아이템·블록·몹·상태 효과·마법 부여·구조물·생물 군계)은 마인크래프트 공식 한국어를
   그대로 쓴다. JEI 검색과 바닐라 화면이 일치해야 한다.
3. **시스템·동작 용어**는 한국 플레이어가 실제로 쓰는 말을 쓴다.
   - 바닐라 화면에 공식 표현이 보이고 커뮤니티에서도 통하면 공식 표현을 쓴다
     (제작법, 마법 부여, 생물 군계, 단축 바, 리스폰, 사전 설정, 키 지정).
   - 바닐라에 없거나 거의 보이지 않고 커뮤니티 외래어가 굳었으면 외래어를 쓴다
     (엔티티, 스폰, 쿨타임, 인벤토리, 월드, 틱, 청크).
   - 문장 속 동작은 한국어 동사로 자연스러운 쪽을 쓴다(순간이동하다).
4. 모드 자체 한국어는 후보로 검토하고, 오래 쓰여 굳은 이름이면 유지한다(AE2의 `천령석`).
5. 위에서 정해지지 않으면 3장의 이름 짓기 순서를 따른다.

기존 번역이 검색성과 일관성을 해치면 그대로 따르지 않는다.

## 3. 표기와 이름 짓기

- 공식 모드명은 원칙적으로 공식 영문 이름을 유지한다.
- 일반 카테고리명은 자연스러운 한국어로 번역한다.
- 아이템 기반 퀘스트 제목은 리소스팩의 확정 아이템 이름을 그대로 사용한다.
- 모드명, 아이템명과 퀘스트 제목의 표기가 충돌하면 이 용어집의 확정 표기를 기준으로 통일한다.
- 용어를 기록할 때 `공식 모드명`, `공통 카테고리명`, `아이템·블록명`, `기술 용어`, `예외적으로 번역하는 고유명사` 중 하나로 종류를 구분한다.

### 이름 짓기 순서

`Sky Stone`을 `천령석`, `스카이 스톤`, `Sky Stone` 중 무엇으로 쓸지 같은 판단은 이 순서로 한다.

1. 바닐라 공식 이름이 있으면 그대로 쓴다.
2. 모드 공식 한국어가 있고 뜻·검색에 문제가 없으면 쓴다(Sky Stone → 천령석).
3. 일반 명사·형용사로 이뤄진 이름은 뜻으로 번역한다(Covered Cable → 피복 케이블).
4. 창작 고유명사와 재료명은 외래어 표기법에 맞춰 음역한다(Fluix → 플루익스, Soularium → 소울라리움).
5. 한국 플레이어가 외래어로 부르는 말은 억지로 번역하지 않는다
   (Dark Steel → 다크 스틸, Press → 프레스, Terminal → 터미널).
6. 음역이 길거나 어색하고 영문으로 통용되면 원문을 유지한다(ME, Ultimine, Neo Vitae 기계명).
7. 뜻을 추측한 새 한자어·조어는 만들지 않는다. 모드 공식 한국어일 때만 예외로 받아들인다.

- 같은 계열의 파생 이름은 기준 이름을 따른다(천령석 → 천령 강철).
- 고유 부분은 음역하고 일반 부분은 번역하는 조합은 허용한다(Certus Quartz → 서투스 석영,
  ME Storage Cell → ME 저장 셀).
- 고유명사의 새 음역이나 뜻 번역을 정하면 용어집에 기록하고, 판단이 애매하면 보류 목록에 둔다.

### 용어를 적용하는 범위

- 확정 용어는 적힌 뜻과 적용 범위에만 적용한다. 철자가 같아도 뜻이 다르면 따로 판단한다.
  예: AE2의 `Press`(각인기 부품)는 `프레스`지만 `Press [키]`는 `누르세요`, `Pressure Plate`는 바닐라
  `압력판`이다.
- 접두사·접미사가 붙은 복합어는 새 용어로 본다. 부분 용어를 기계적으로 이어 붙이지 않고 전체
  뜻과 기존 번역을 확인한다.
- 이 문서는 명사·이름 중심이다. 영어 동사·형용사로 쓰인 경우(`upgrade your tools`, `powered`)는
  문장에 맞는 한국어 표현을 쓴다.
- 더 쉬운 한국어 일반어가 있으면 억지로 외래어를 쓰지 않고, 굳은 외래어를 억지로 우리말로
  바꾸지도 않는다.
- 설명문에서 확정 용어를 매번 되풀이할 필요는 없다. 생략하거나 동사로 풀어도 되지만, 같은 대상을
  확정 용어의 다른 표기(동의어)로 부르지는 않는다.
- 비고의 `~와 섞지 않음`은 실제로 혼동이 생긴 표기에만 적는다.

## 6. 용어 추가 및 변경 규칙

- 여러 파일이나 모드에서 반복 사용될 용어, 검색되는 이름, 이미 서로 다른 번역이 섞여 있는
  용어만 추가한다. 한 번만 나오는 평범한 단어와 동사는 추가하지 않는다.
- 새 용어는 2장 결정 기준과 3장 이름 짓기 순서를 거쳐 정하고, 왜 그 표기를 골랐는지 비고에
  한 줄로 남긴다.
- `Pickup`처럼 문맥에 따라 번역이 달라질 수 있는 용어는 적용 범위를 반드시 기록한다.
- 확정 용어를 변경할 때는 기존 사용 위치를 찾아 함께 교정하고, 변경 이유와 적용 범위를 비고에 기록한다.
- 2026-09-29 용어 기준 변경은 수천 곳이 문맥마다 달라 일괄 치환하지 않는다. 품질 재검수 계열을
  진행하며 문맥을 확인해 교체한다. 이미 끝난 1·2순위 계열은 8.1-stable.10에서 교체를 마쳤고,
  아이템 이름과 함께 바꿔야 하는 `솔라리움`만 Ender IO 계열에서 처리한다.
  대상: `개체`→`엔티티`, `재사용 대기시간`→`쿨타임`, 동작 뜻의 `생성`→`스폰`, 이름 속
  `순간이동`→`텔레포트`, `재생성`→`리스폰`, `키 설정`→`키 지정`, `단축바`→`단축 바`,
  `생물군계`→`생물 군계`, `솔라리움`→`소울라리움`, `하늘 강철`·`스카이 스틸`→`천령 강철`,
  `키친싱크 모드팩` 풀어 쓰기.
- 문맥상 예외가 필요하면 기본 용어를 바꾸지 말고 예외 사유와 적용 범위를 기록한다.
