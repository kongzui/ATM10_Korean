# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.8

전체 번역 품질 재검수의 1순위인 **팩 공통 진행 퀘스트**를 다시 다듬었어요. stable.7까지의
모든 번역을 포함하며 ATM10 **8.1 / Minecraft 1.21.1**용이에요. 새 모드 번역은 없어요.

- FTB Quests 19파일 2,023키를 영어 원문과 다시 대조해 575키를 고치고 1,448키를 유지했어요.
- 번역체(당신·그것·~할 것입니다), 모드명 음역·뜻 번역, power→힘 같은 오역을 바로잡았어요.
- 영어가 섞여 남은 문장, 내용을 줄여 버린 설명, 문장 끝에 몰아 둔 색상 코드 같은 깨진 표시도
  고쳤어요.
- KubeJS 툴팁 7줄·아이템 이름 1개와 FTB Quests Lang Splitter 안내 3키를 다듬었어요.

## 설치

1. Minecraft를 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.8_overrides.zip`의 `config/`와 `kubejs/`를 인스턴스 루트에 병합해요.
3. `ATM10_Korean_8.1-stable.8_resourcepack.zip`을 압축 그대로 `resourcepacks/`에 넣어요.
4. 게임 언어를 한국어로 설정하고 새 팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요.

이번에는 퀘스트와 KubeJS가 바뀌었으므로 override ZIP도 함께 적용해야 해요. 개인 설정은
포함하지 않으며 7.1 안정판은 그대로 유지해요.

## 검증 범위와 남은 표시

현재 인스턴스의 분할 영어 퀘스트와 키 단위로 대조하고, 자료형·문단 수·색상 코드·자리표시자·
숫자·`\n` 줄바꿈을 검사해요. 기준 커밋 대비 키 추가·삭제가 없는지, 수정본과 산출물·8.1 수동
검수 목록이 일치하는지, KubeJS는 문자열 밖 코드가 그대로인지와 문법을 확인해요.

영어 원문이 그대로 남은 KubeJS 안내(구버전 기계 경고, JEI 정보 등)는 신규 번역이라 이번
범위에서 바꾸지 않았어요. 게임 내 퀘스트 화면은 아직 확인하지 않았어요.
[재검수 보고](../../versions/8.1/reports/quality_rereview_pack_progress.md)를 참고하세요.
