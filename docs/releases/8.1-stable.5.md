# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.5

Logistics Networks의 일반 언어, 노드·렌치·필터·컴퓨터 가이드를 추가한 누적 배포예요.
기존 Auroral·Neo Vitae·Ad Astra 계열과 나머지 번역도 모두 포함해요.
ATM10 **8.1 / Minecraft 1.21.1**용이며 7.1 안정판은 그대로예요.

## 설치

1. Minecraft를 완전히 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.5_overrides.zip` 안의 `config/`와 `kubejs/`를
   ATM10 8.1 인스턴스 루트에 병합해요.
3. `ATM10_Korean_8.1-stable.5_resourcepack.zip`은 압축을 풀지 않고 `resourcepacks/`에 넣어요.
4. 게임 언어를 한국어로 설정하고 새 리소스팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요. 개인 단축키·그래픽 설정은 포함하지 않아요.

이번 override 내용은 stable.4와 같아요. 처음 설치하거나 오래된 보조 코드가 남아 있다면
두 ZIP을 함께 사용하세요. 보조 번역 실행 코드는 계속 제외하며 기존 네 파일은 주석 전용이에요.

## 추가한 번역

| 범위 | 전체 | 기존 한국어 재사용 | 새 한국어 | 원문 표기 유지 |
|---|---:|---:|---:|---:|
| Logistics Networks 일반 언어 | 454키 | 0 | 434 | 20 |
| 가이드 이름·설명 | 2키 | 0 | 2 | 0 |
| GuideME 가이드 | 17페이지 | 0 | 17페이지 | 공식 명칭·코드 예시는 보존 |

- 노드·채널·렌치·필터·컴퓨터·설정·발전 과제·단축키 문구를 전체 검수했어요.
- 송신·수신 방향을 구분하고, Ars Nouveau 자원은 기존 용어집의 `마나`로 통일했어요.
- 가이드 목차·본문·표·그림 설명과 제작법 대체 문구를 번역했어요. 원본 스크린샷의 영어는 유지해요.
- 현재 코드와 다른 채널 번호, 업그레이드 적용 범위, 가상 필터와 붙여넣기 설명을 교정했어요.
- 가이드 이름·설명은 한국어 언어 키를 사용하며 다른 언어용 영어 fallback을 보존해요.
- FTB Quests 1,000파일·66챕터와 KubeJS 871파일에서 관련 참조가 없어 수정하지 않았어요.

## 검증과 확인 범위

현재 JAR의 영어 전체와 검수 해시, JSON 중복·자료형·키, 자리표시자·숫자·서식·개행을 검증해요.
GuideME의 YAML 구조, 제작법 태그, 이미지, 링크, 인라인 코드와 기존 문단 앵커 두 개도 검사해요.
채널 번호 교정은 코드로 확인한 원문 한 곳에만 고정하고 나머지 숫자는 보존해요.

기존 배포 검증과 고정 해시 검사를 유지하면서 이번 모드의 검증을 누적했어요.
전체 JSON/SNBT/JS 문법과 보조 코드 부재, ZIP 루트·CRC·내용을 검사해요.
파일 검증과 실제 게임 화면 검증은 별개예요. 실제 게임에서 UI 폭, 필터 조작, 가이드 이동은
아직 확인하지 않았으며 새 리소스팩을 활성화한 뒤 확인해야 해요.

## 재검증과 ZIP 생성

```powershell
python scripts/verify_logisticsnetworks_translation.py
python scripts/verify_stable_release.py --version 8.1
python scripts/package_compat_release.py --version 8.1
```

검증 보고서는 `versions/8.1/reports/8.1-stable.5_stable_validation.json`, ZIP 목록은
`versions/8.1/manifests/8.1-stable.5_packages.json`에 저장해요.
배포 파일은 `temp/releases/8.1-stable.5/`의 ZIP 두 개예요.
이 기기의 선택 적용 결과는 `versions/8.1/reports/logisticsnetworks_apply.json`에 따로 기록해요.
