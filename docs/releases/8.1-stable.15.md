# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.15

전체 번역 품질 재검수 6순위 **Allthemodium·ATM 광물**을 반영했어요. stable.14까지의 모든 번역을
포함하며 ATM10 **8.1 / Minecraft 1.21.1**용이에요. 새 모드 번역은 없어요.

- Allthemodium, All The Ores, All The Compressed, All the Arcanist Gear, All the Wizard Gear 5개 모드
  언어 2,662키를 영어 원문과 다시 대조해 201키를 고치고 2,461키를 유지했어요.
- All The Ores의 `Other ~ Ore`를 `기타 ~ 광석`으로 잘못 옮긴 17개 광석 이름을 차원 이름인
  `디 아더 ~ 광석`으로 고쳤어요.
- 압축 블록 1,796키는 원래 블록의 확정 한국어와 프로그램으로 대조해 18개 블록의 9단계 이름을
  맞췄어요(바닐라 `벌집 조각 블록`·`단단한 진흙`·`블레이즈 막대기`, 용어집 `레드스톤 결정` 등).
- 재료 막대는 바닐라처럼 `막대기`, 재료 부품 Gear는 `기어`로 통일하고, 바닐라 생물 군계 이름
  `깊은 어둠`·`엔드 고지`에 맞췄어요.
- Allthemodium Patchouli 안내서의 표시 필드 47개도 다시 검토해 음식 수치 `배고픔`과 생물 군계 이름을 고쳤어요.

## 설치

1. Minecraft를 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.15_resourcepack.zip`을 압축 그대로 `resourcepacks/`에 넣어요.
3. stable.14의 override를 적용하지 않았다면 `ATM10_Korean_8.1-stable.15_overrides.zip`의
   `config/`와 `kubejs/`도 인스턴스 루트에 병합해요.
4. 게임 언어를 한국어로 설정하고 새 팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요.

이번 변경은 리소스팩 언어 파일과 안내서 파일만이에요. 개인 설정은 포함하지 않으며 7.1 안정판은
그대로 유지해요.

## 검증 범위와 남은 표시

현재 JAR 영어 원문과 키 단위로 대조하고 자리표시자·색상 코드·줄바꿈 수를 검사해요. 기준 커밋 대비 키
목록·순서가 그대로인지, 작업 원본과 산출물이 일치하는지, 안내서의 구조와 Patchouli 태그가 그대로인지
확인해요. 게임 내 화면은 아직 확인하지 않았어요.
[재검수 보고](../../versions/8.1/reports/quality_rereview_atm_ores.md)를 참고하세요.
