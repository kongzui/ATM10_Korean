# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.14

전체 번역 품질 재검수 5순위 **초반 기반 도구·기계·물류**와 보류 용어 확정을 반영했어요. stable.13까지의
모든 번역을 포함하며 ATM10 **8.1 / Minecraft 1.21.1**용이에요. 새 모드 번역은 없어요.

- Iron Furnaces, Mining Gadgets, Building Gadgets 2, Functional Storage, XNet, Pipez, QuarryPlus 등 20개
  모드 언어 1,769키를 영어 원문과 다시 대조해 126키를 고치고 1,643키를 유지했어요.
- QuarryPlus에서 Quarry를 `쿼리`로 잘못 옮긴 이름을 `채석기`로 고치고, 같은 뜻의 퀘스트 문장 4곳도
  `채석기`로 맞췄어요.
- Void 업그레이드는 `제거 업그레이드`, 몹이 나타나는 뜻은 `스폰`, 음식 수치는 `배고픔`으로 통일했어요.
- 보류 용어 확정분(배고픔, 습격자, 구조물 크기 표기, 구조물 고유명 등)을 앞선 계열 62키에 반영했어요.
- 자리표시자 순서가 뒤바뀐 Building Gadgets 2 메시지, crash를 `충돌`로 옮긴 QuarryPlus 경고 같은 오역과
  명령 결과·설정 설명의 번역투를 고쳤어요.

## 설치

1. Minecraft를 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.14_overrides.zip`의 `config/`와 `kubejs/`를 인스턴스 루트에 병합해요.
3. `ATM10_Korean_8.1-stable.14_resourcepack.zip`을 압축 그대로 `resourcepacks/`에 넣어요.
4. 게임 언어를 한국어로 설정하고 새 팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요.

퀘스트 문장도 바뀌었으므로 override ZIP도 함께 적용해야 해요. 개인 설정은 포함하지 않으며 7.1 안정판은
그대로 유지해요.

## 검증 범위와 남은 표시

현재 JAR 영어 원문과 키 단위로 대조하고 자리표시자·색상 코드·줄바꿈 수를 검사해요. 기준 커밋 대비 키
목록·순서가 그대로인지, 작업 원본과 산출물이 일치하는지 확인해요. Building Gadgets 2 Patchouli
가이드북과 Energy Meter 가이드는 이번 범위에 들어가지 않았어요. 게임 내 화면은 아직 확인하지 않았어요.
[재검수 보고](../../versions/8.1/reports/quality_rereview_early_infra.md)를 참고하세요.
