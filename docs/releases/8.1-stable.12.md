# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.12

전체 번역 품질 재검수 3순위 **Sophisticated 계열**(배낭·저장소)을 다시 다듬었어요. stable.11까지의
모든 번역을 포함하며 ATM10 **8.1 / Minecraft 1.21.1**용이에요. 새 모드 번역은 없어요.

- Sophisticated Core·Backpacks·Storage·Storage In Motion 언어 1,137키를 영어 원문과 다시 대조해
  112키를 고치고 1,025키를 유지했어요.
- Chipped 연동 업그레이드 이름을 실제 Chipped 블록 이름(유리공·목수·직조·땜장이 작업대)에 맞췄어요.
- 우클릭·좌클릭, 웅크린 채 우클릭, 제작 칸, 엔티티, 쿨타임, 스폰 같은 용어집 표기와 바닐라
  `속도 감소`에 맞추고, 제한된 통 설정 이름을 아이템 이름과 통일했어요.
- `성공적으로 ~되었습니다` 같은 번역투와 조사(`은(는)`, `을(를)`)를 다듬고, 명령 결과를 완결된
  문장으로 고쳤어요.

## 설치

1. Minecraft를 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.12_resourcepack.zip`을 압축 그대로 `resourcepacks/`에 넣어요.
3. stable.10 이후 override를 적용하지 않았다면 `ATM10_Korean_8.1-stable.12_overrides.zip`의
   `config/`와 `kubejs/`도 인스턴스 루트에 병합해요.
4. 게임 언어를 한국어로 설정하고 새 팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요.

이번 변경은 리소스팩 언어 파일만이에요. 개인 설정은 포함하지 않으며 7.1 안정판은 그대로 유지해요.

## 검증 범위와 남은 표시

현재 JAR 영어 원문과 키 단위로 대조하고 자리표시자·색상 코드·줄바꿈 수를 검사해요. 기준 커밋
대비 키 목록·순서가 그대로인지, 작업 원본과 산출물이 일치하는지 확인해요. 게임 내 화면은 아직
확인하지 않았어요. [재검수 보고](../../versions/8.1/reports/quality_rereview_sophisticated.md)를
참고하세요.
