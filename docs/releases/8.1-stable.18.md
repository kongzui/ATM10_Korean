# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.18

전체 번역 품질 재검수 9순위 **Mystical Agriculture**를 반영했어요. stable.17까지의 모든 번역을 포함하며
ATM10 **8.1 / Minecraft 1.21.1**용이에요. 새 모드 번역은 없어요.

- Mystical Agriculture·Mystical Agradditions 언어 849키를 영어 원문과 다시 대조해 60키를 고치고
  789키를 유지했어요.
- Mystical Agriculture 퀘스트 277키 중 140키를 다듬었어요. 작물 부제의 `티어`를 `등급`으로 통일했고
  `당신`·반말·해요체, `인챈터`, `오른쪽 클릭`을 고쳤어요.
- 이름을 바로잡았어요: `%s 에센스`(`철의 에센스` → `철 에센스`), `마법 부여기`(인챈터), `기계 프레임`,
  바닐라 효과 이름 `속도 증가`·`속도 감소`, `경험 구슬`, `흙 길`, `드래곤 알 덩어리`(청크 오역),
  작물 재료 `소울라리움`·`생동 합금`·`시그널륨`·`아이언우드`·`파이어리 주괴`·`석영 농축 철`.
- 작물 설정 이름 3개를 고쳤어요: `천령 강철`(스카이 스틸), `다크스톤`(어둠돌),
  `Regions Unexplored 목재`(미탐사 목재).
- ATM의 별 퀘스트의 `경험치 정수`도 Mystical Agriculture 이름 `경험치 에센스`로 맞췄어요.
- 챕터 제목은 이미 `Mystical Agriculture`예요. 옛 병합 파일에만 남은 `신비농업`은 분할 파일로 덮여요.

## 설치

1. Minecraft를 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.18_resourcepack.zip`을 압축 그대로 `resourcepacks/`에 넣어요.
3. `ATM10_Korean_8.1-stable.18_overrides.zip`의 `config/`와 `kubejs/`를 인스턴스 루트에 병합해요.
   퀘스트 문장과 작물 설정 이름이 바뀌었으므로 override도 함께 적용해야 해요.
4. 게임 언어를 한국어로 설정하고 새 팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요.

개인 설정은 포함하지 않으며 7.1 안정판은 그대로 유지해요.

## 검증 범위와 남은 표시

현재 JAR 영어 원문과 키 단위로 대조하고 자리표시자·색상 코드·줄바꿈·숫자 수를 검사해요. 작물 설정은
`name` 밖의 구조가 기준 커밋과 같은지 확인해요. 게임 내 화면은 아직 확인하지 않았어요.
[재검수 보고](../../versions/8.1/reports/quality_rereview_mystical.md)를 참고하세요.
