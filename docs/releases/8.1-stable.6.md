# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.6

Step Crafter의 블록·툴팁·제작 상태·설정 79키를 추가한 누적 배포예요.
기존 Auroral·Neo Vitae·Ad Astra·Logistics Networks와 나머지 번역도 모두 포함해요.
ATM10 **8.1 / Minecraft 1.21.1**용이며 7.1 안정판은 그대로예요.

## 설치

1. Minecraft를 완전히 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.6_overrides.zip`의 `config/`와 `kubejs/`를
   ATM10 8.1 인스턴스 루트에 병합해요.
3. `ATM10_Korean_8.1-stable.6_resourcepack.zip`은 압축을 풀지 않고 `resourcepacks/`에 넣어요.
4. 게임 언어를 한국어로 설정하고 새 리소스팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요. 개인 단축키·그래픽 설정은 포함하지 않아요.

이번 override 내용은 stable.5와 같아요. 처음 설치하거나 오래된 보조 코드가 남아 있다면
두 ZIP을 함께 사용하세요. 보조 번역 실행 코드는 계속 제외하며 기존 네 파일은 주석 전용이에요.

## 추가한 번역

- 현재 Step Crafter 0.1.8의 영어 79키 전체를 검수했어요.
- 신규 한국어 78키, 기존 한국어 재사용 0키, 공식 모드명 원문 유지 1키예요.
- 단계 제작기·단계 요청기·각 관리자·단계 제작 모니터를 구분하고 Refined Storage 용어와 맞췄어요.
- 최소·최대 재고와 묶음 크기, 상태 메시지·조작 안내·에너지와 속도 설정을 번역했어요.
- 별도 가이드는 없고, 제작법 해금용 발전 과제 48파일에도 표시 문구가 없어요.
- FTB Quests 1,000파일·66챕터와 KubeJS 871파일에 관련 참조가 없어 수정하지 않았어요.

## 검증과 확인 범위

현재 JAR의 영어 전체와 검수 해시, JSON 중복·자료형·키 순서·누락, 자리표시자·숫자·서식·
개행·이스케이프를 검증해요. 속도 계산식과 필요한 수량의 별표 주석도 보존해요.
기존 누적 배포 검증·고정 해시 검사에 이번 모드의 검증을 추가했어요.
전체 JSON/SNBT/JS 문법, 보조 코드 부재, ZIP 루트·CRC·내용 해시를 검사해요.

실제 게임 화면은 확인하지 않았어요. 설치 후 블록 이름·툴팁·수량 설정·관리자 검색·제작 상태
화면을 확인해야 해요. 파일 적용과 게임 안에서 리소스팩 활성화는 구분해요.

## 재검증과 ZIP 생성

```powershell
python scripts/verify_stepcrafter_translation.py
python scripts/verify_stable_release.py --version 8.1
python scripts/package_compat_release.py --version 8.1
```

검증 보고서는 `versions/8.1/reports/8.1-stable.6_stable_validation.json`, ZIP 목록은
`versions/8.1/manifests/8.1-stable.6_packages.json`에 저장해요.
배포 파일은 `temp/releases/8.1-stable.6/`의 ZIP 두 개예요.
이 기기의 선택 적용 결과는 `versions/8.1/reports/stepcrafter_apply.json`에 따로 기록해요.
