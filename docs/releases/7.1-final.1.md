# ATM10 7.1 한국어 최종 수정판 · 7.1-final.1

이 배포에는 Mouse Tweaks 화면 충돌이 있어요. [7.1-stable.1 안정판](7.1-stable.1.md)을 사용해요.
아래는 이전 배포 당시 기록이에요.

ATM10 **7.1 / Minecraft 1.21.1**용 전체 누적 배포예요. 7.1의 기존 번역을 유지하면서
배포 오류를 고쳤어요. 8.1의 모드 번역이나 퀘스트 구조는 섞지 않았어요.

## 설치 및 기존판 교체

1. Minecraft를 완전히 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_7.1-final.1_overrides.zip`을 풀고 내부 **config/**와 **kubejs/**를
   7.1 인스턴스 루트에 병합해요. 같은 이름의 파일은 교체해요.
3. `ATM10_Korean_7.1-final.1_resourcepack.zip`은 압축을 풀지 않고 **resourcepacks/**에 넣어요.
4. 게임에서 언어를 한국어로 설정하고 새 리소스팩을 활성화해요. 기존 `ATM10_Korean` 폴더팩이나
   구버전 ZIP은 비활성화해서 새 팩 하나만 사용해요. 기존 폴더팩에 파일만 병합하면 제외한
   Modern UI 개인 글꼴이 남을 수 있으므로 새 ZIP을 그대로 사용해요.
5. 시작 스크립트가 바뀌었으므로 **게임을 완전히 다시 실행**해요. 리소스팩 새로고침만으로는
   KubeJS 시작 오류 수정이 반영되지 않아요.

리소스팩 ZIP 루트에는 `pack.mcmeta`·`assets/`, 덮어쓰기 ZIP 루트에는 `config/`·`kubejs/`가 있어요.
퀘스트나 스크립트를 서버에서 제공한다면 서버 운영자도 대응 파일을 교체해야 해요.
8.1에는 이 ZIP을 적용하지 말고 `8.1-compat.2`를 사용해요.

## 수정 및 검증 범위

- AppleSkin·EnderDrives·Mouse Tweaks 스크립트의 Rhino `const` 재선언 오류를 고쳤어요.
- Mouse Tweaks의 블록 내 함수 선언도 함수 표현식으로 바꿔 화면 갱신 시 호출되도록 했어요.
- `herbs.json`·`grapes.json` 끝의 중복 닫기를 제거하고 Modern UI 개인 글꼴을 제외했어요.
- 기존 모드 언어 145,570개 값과 FTB Quests·나머지 KubeJS 내용은 그대로예요. 새 번역은 없어요.
- 전체 JSON·SNBT·JS 문법, 이전 산출물 비교, 글꼴 참조, ZIP CRC·내용 해시를 검사해요.
- 실제 설치된 Rhino 2101.2.7-build.81에서 기존 오류를 재현하고 수정본의 초기화와 반복 콜백,
  무관한 문구·화면 필터, 서버 환경과 관련 모드 미설치 조건을 검사했어요.
- 게임 API는 검사 대역을 사용했어요. 실제 Minecraft 화면·NeoForge 이벤트 연결은 재확인 전이에요.

사용자의 명시적 요청으로 7.1 보존 산출물에도 이번 수정만 반영했어요. 실제 인스턴스에는
자동 적용하지 않았어요. 최종 수정판은 기존 번역 범위의 배포이며, 전체 모드 완역을 뜻하지 않아요.

## 재검증 및 ZIP 생성

`JAVA21`은 설치된 Java 21 실행 파일, `JAVAC`은 설치된 JDK의 javac 실행 파일로 바꿔요.

```powershell
python scripts/verify_startup_hotfix.py --version 7.1 --instance "7.1 인스턴스 경로" --java "JAVA21" --javac "JAVAC"
python scripts/package_compat_release.py --version 7.1
```

결과는 `temp/releases/7.1-final.1/`에 ZIP 두 개, `INSTALL.md`, `SHA256.json`으로 생성돼요.
