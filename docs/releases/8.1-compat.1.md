# ATM10 한국어 호환판 8.1-compat.1

이 배포에서는 KubeJS 시작 오류가 확인됐어요. 새 설치와 업데이트는
[8.1-compat.3 수정판](8.1-compat.3.md)을 사용해요. 아래 내용은 첫 배포 당시 기록이에요.

배포 대상은 **ATM10 8.1 / Minecraft 1.21.1**이에요. 7.1의 검수 번역과 이미 완료한
8.1 번역을 합친 누적판이며, 이전 한국어 팩을 먼저 설치할 필요는 없어요.
게임 화면 확인은 사용자의 요청으로 후속 확인에 남겼어요. 파일 검증과 게임 실행 검증은 달라요.

## 설치

1. Minecraft를 완전히 종료하고 현재 리소스팩과 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-compat.1_resourcepack.zip`을 **8.1 인스턴스의 `resourcepacks/`**에
   그대로 넣어요. 압축을 풀지 않아도 돼요.
3. 게임의 언어를 한국어로 설정하고 리소스팩 메뉴에서 새 팩을 사용 중인 목록으로 옮겨요.
   예전 `ATM10_Korean` 폴더나 ZIP이 있다면 함께 활성화하지 말고 새 팩 하나만 사용해요.
   다른 번역팩과 함께 사용한다면 이 팩을 우선 적용하도록 위에 배치해요.
4. 퀘스트와 KubeJS도 한글화하려면 게임을 다시 종료한 뒤
   `ATM10_Korean_8.1-compat.1_overrides.zip`의 **`config/`와 `kubejs/`를 8.1 인스턴스 루트에
   병합**해요. 이 ZIP은 `resourcepacks/`에 넣는 파일이 아니에요.
5. 게임을 다시 실행해 JEI 검색, 퀘스트 목차·제목, 가이드와 툴팁을 확인해요.
   서버에서 퀘스트·서버 스크립트를 제공하는 경우 서버 운영자도 서버의 대응 파일을 적용해야 해요.

리소스팩 ZIP 바로 아래에는 `pack.mcmeta`와 `assets/`가 있어요.
ZIP 안의 `ATM10_Korean/` 같은 상위 폴더를 한 번 더 감싼 구조가 아니에요.
7.1 월드나 모드 JAR을 포함하지 않으며, 이 파일로 월드를 자동 이전하지 않아요.

## 이번 호환판에서 고친 내용

- 기존 모드의 8.1 신규·변경 키 누락 111개를 채우고 기존 값 10개를 교정했어요.
- `herbs.json`, `grapes.json`의 중복 `] }`를 제거하고 빌드·검증기에 재발 방지를 넣었어요.
- 불필요한 `assets/modernui/font/gyeonggi_title_medium.ttf`를 제외했어요.
  현재 리소스팩이 실제로 사용하는 Minecraft 글꼴과 출처 안내는 유지해요.
- 리소스팩 설명의 버전을 7.1에서 8.1로 바꿨어요.
- Cataclysm·Relics 챕터의 7.1 구조 잔여를 현재 8.1 구조로 맞췄어요.
  다른 챕터도 한국어 `custom_name` 이외의 구조가 현재 원본과 같은지 확인했어요.
- PneumaticCraft 가이드에 경험치 흡수·차원 이동 변경과 새 차원 조건 위젯을 반영했어요.

## 번역 범위와 후속 업데이트

이 배포는 기존 번역의 8.1 호환판이에요. 신규 후보 11개 네임스페이스, 4,779키는 후속
누적 업데이트에서 번역해요. Neo Vitae, Ad Astra와 애드온, Logistics Network, Auroral,
Step Crafter, Borderless, Better Advanced Tooltips, Moog's Structures, Common Storage Lib,
Invasive Optimizations가 해당해요. 관련 퀘스트 한국어는 이미 포함된 범위가 있어요.

기존 모드에서도 7.1 프로젝트 산출물에 없던 영어 키 2,120개는 그대로 남아 있어요.
이는 이번 버전업에서 누락한 키 수가 아니며, 일부는 모드 자체 한국어 또는 다른 네임스페이스를
통해 표시될 수 있어요. 기존 번역의 표현 개선과 퀘스트 제목 일치 검토 후보도 후속 작업이에요.
공식 모드명·명령어·저작권 표시는 의도적으로 영어를 유지할 수 있어요.

후속판은 같은 `ATM10_Korean` 팩에 번역을 더해 완성된 누적 ZIP으로 제공해요.
여러 버전의 ZIP을 동시에 활성화할 필요는 없어요.

## 검증과 문제 제보

JSON·SNBT·JavaScript 문법, 언어 키와 자리표시자·서식, 글꼴 참조, 챕터·설정 구조,
원본 해시와 ZIP 내부 파일을 검사했어요. 세부 결과는
`versions/8.1/reports/compat_validation.json`과 `compat_release.md`에 기록해요.

기존 7.1 배포가 작동하지 않았다는 피드백의 원인을 두 JSON 오류나 Modern UI 글꼴로
단정하지는 않아요. 이번에는 해당 파일 문제와 ZIP 루트 구조를 함께 바로잡았어요.
문제가 있다면 ATM10 버전, 사용한 ZIP 이름, 리소스팩 활성화 상태와 관련 로그를 함께 알려 주세요.
