# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.9

전체 번역 품질 재검수 2순위 **항상 보는 공통 UI**의 1부(JEI·Jade·FTB 계열)를 다시 다듬었어요.
stable.8까지의 모든 번역을 포함하며 ATM10 **8.1 / Minecraft 1.21.1**용이에요. 새 모드 번역은 없어요.

- JEI·Jade·FTB Quests·FTB Chunks·FTB Teams·FTB Ultimine·FTB Essentials·FTB Filter System
  언어 8개 2,197키를 영어 원문과 다시 대조해 142키를 고치고 2,055키를 유지했어요.
- 참/거짓 설명을 켜면/끄면으로, 번역체 수동태(~에 의해)와 어색한 어순을 자연스럽게 바꾸고,
  모드명(FTB Quests, CustomNPCs, BuildCraft, Botania)은 공식 영문 이름으로 통일했어요.
- 마인크래프트 공식 용어(주 손, 단축바, 생물군계, 개체)에 맞췄어요.

## 설치

1. Minecraft를 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.9_resourcepack.zip`을 압축 그대로 `resourcepacks/`에 넣어요.
3. stable.8 override를 적용하지 않았다면 `ATM10_Korean_8.1-stable.9_overrides.zip`의
   `config/`와 `kubejs/`도 인스턴스 루트에 병합해요.
4. 게임 언어를 한국어로 설정하고 새 팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요.

이번 변경은 리소스팩 언어 파일만이에요. 개인 설정은 포함하지 않으며 7.1 안정판은 그대로 유지해요.

## 검증 범위와 남은 표시

현재 JAR 영어 원문과 키 단위로 대조하고 자리표시자·색상 코드·줄바꿈 수를 검사해요. 기준 커밋
대비 키 목록·순서가 그대로인지, 작업 원본과 산출물이 일치하는지 확인해요.
JourneyMap·Curios·Waystones·Nature's/Explorer's Compass는 2순위 2부로 미뤘어요.
게임 내 화면은 아직 확인하지 않았어요.
[재검수 보고](../../versions/8.1/reports/quality_rereview_common_ui.md)를 참고하세요.
