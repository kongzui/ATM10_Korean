# ATM10 7.1 한국어 안정판 · 7.1-stable.1

ATM10 **7.1 / Minecraft 1.21.1**용 전체 누적 배포예요. 이전 번역팩을 먼저 설치할 필요는 없어요.
화면·툴팁·채팅을 가로채는 보조 번역 실행 코드를 제외했어요. 일반 언어·퀘스트·가이드와
ATM10 원래 스크립트의 번역은 유지하고, 보조 기능으로만 번역하던 문구는 원래 표시를 사용해요.

## 설치와 이전 배포 교체

1. Minecraft를 완전히 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_7.1-stable.1_overrides.zip`을 풀고 내부 **config/**와 **kubejs/**를
   **ATM10 7.1 인스턴스 루트**에 병합해요. 같은 이름의 파일을 반드시 교체해요.
3. 다음 네 파일은 주석만 있어요. 이전 코드에 덮어쓰면 보조 기능이 꺼져요.
   리소스팩만 바꾸면 기존 보조 코드는 계속 실행되므로 override도 함께 교체해야 해요.

   - `kubejs/startup_scripts/appleskin_debug_labels.js`
   - `kubejs/startup_scripts/mousetweaks_config_labels.js`
   - `kubejs/startup_scripts/enderdrives_messages.js`
   - `kubejs/client_scripts/enderdrives_tooltips.js`

4. `ATM10_Korean_7.1-stable.1_resourcepack.zip`은 압축을 풀지 않고 **resourcepacks/**에 넣어요.
5. 게임 언어를 한국어로 설정하고 새 리소스팩만 활성화해요. 기존 폴더팩·구버전 ZIP은
   비활성화해요. 기존 폴더에 병합하지 않고 새 ZIP을 사용하면 제외한 개인 글꼴도 따라오지 않아요.
6. 게임을 완전히 다시 실행해요. 리소스팩 새로고침만으로 시작 스크립트 변경은 반영되지 않아요.

네 파일을 직접 삭제하는 방법도 가능하지만, 새 override로 교체했다면 별도로 삭제할 필요는
없어요. 예전 보조 코드를 다른 이름의 `.js`로 복사했다면 해당 사본은 스크립트 폴더 밖에 보관해요.
다른 ATM10 원래 스크립트는 삭제하지 않아요. 서버에서도 이전 보조 파일을 설치했다면 같은
교체가 필요해요. 다른 ATM10 버전에 이 ZIP을 적용하지 않아요.

## 유지한 수정과 검증 범위

- Herbs and Harvest 가이드 JSON 2개의 중복 닫기 수정과 Modern UI 개인 글꼴 제외를 유지해요.
- 일반 언어 값 145,570개를 유지했어요. 이번 새 번역은 없어요.
- FTB Quests와 나머지 KubeJS 내용은 이전 해당 버전 배포와 같아요.
- 전체 JSON·SNBT·JS 문법, 보조 코드 부재, 기존 설치 덮어쓰기 전환과 ZIP 내용·CRC를 검사해요.
- 이번 안정판은 보고된 보조 번역 오류의 실행 코드를 포함하지 않아요.
- 2026-09-09 기록: 사용자가 안정판 정상 작동을 확인했어요. 버전별·화면별 상세 목록은
  받지 않았으므로 이 버전의 모든 모드를 검증했다는 뜻은 아니에요.
- 사용자가 직접 설치하기로 했으므로 실제 인스턴스에는 적용하지 않았어요.

보조 기능의 제외 범위와 향후 검토는 저장소의 `docs/AUXILIARY_TRANSLATION_SCRIPTS.md`에 있어요.

## 재검증과 ZIP 생성

```powershell
python scripts/verify_stable_release.py --version 7.1
python scripts/package_compat_release.py --version 7.1
```

결과는 `temp/releases/7.1-stable.1/`에 ZIP 두 개, INSTALL.md와 SHA256.json으로 생성돼요.
