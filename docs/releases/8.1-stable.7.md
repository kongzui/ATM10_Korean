# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.7

Better Advanced Tooltips의 설정 5키를 추가해요. stable.6까지의 모든 번역을 포함하며
ATM10 **8.1 / Minecraft 1.21.1**용이에요. 기존 한국어 재사용 0키, 신규 번역 5키예요.

## 설치

1. Minecraft를 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.7_overrides.zip`의 `config/`와 `kubejs/`를 인스턴스 루트에 병합해요.
3. `ATM10_Korean_8.1-stable.7_resourcepack.zip`을 압축 그대로 `resourcepacks/`에 넣어요.
4. 게임 언어를 한국어로 설정하고 새 팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요.

override 내용은 stable.6과 같아요. 처음 설치하거나 오래된 보조 코드가 남아 있다면 두 ZIP을
함께 사용해요. 개인 설정은 포함하지 않으며 7.1 안정판은 그대로 유지해요.

## 검증 범위와 남은 표시

현재 JAR의 영어·검수 기록·JSON·키·보호 문자열, 기존 번역 보존, 전체 JSON/SNBT/JS 문법과
ZIP의 CRC·전체 내용을 검사해요. 별도 가이드나 관련 FTB Quests·KubeJS 문구는 없어요.

연료 툴팁의 `Fuel:`과 데이터 오류 안내는 모드 코드에 직접 들어 있어 원문으로 남아요.
보조 번역 코드는 추가하지 않았어요. [표시 경로 근거](../../versions/8.1/reports/betteradvancedtooltips_translation.md)를 참고하세요.
게임 내 설정 화면·툴팁은 아직 확인하지 않았어요. 파일 적용과 팩 활성화는 별개예요.

## 재검증과 ZIP 생성

```powershell
python scripts/verify_betteradvancedtooltips_translation.py
python scripts/verify_stable_release.py --version 8.1
python scripts/package_compat_release.py --version 8.1
```

검증 보고서는 `versions/8.1/reports/8.1-stable.7_stable_validation.json`, ZIP 목록은
`versions/8.1/manifests/8.1-stable.7_packages.json`이에요.
배포 파일은 `temp/releases/8.1-stable.7/`의 ZIP 두 개예요.
선택 적용 결과는 `versions/8.1/reports/betteradvancedtooltips_apply.json`에 기록해요.
