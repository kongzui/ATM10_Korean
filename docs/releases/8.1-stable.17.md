# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.17

전체 번역 품질 재검수 8순위 **Mekanism 계열**을 반영했어요. stable.16까지의 모든 번역을 포함하며
ATM10 **8.1 / Minecraft 1.21.1**용이에요. 새 모드 번역은 없어요.

- Mekanism 본체와 Generators, Tools, MoreMachine 등 8개 모드 언어 5,216키를 영어 원문과 다시 대조해
  1,398키를 고치고 3,818키를 유지했어요. 설정 화면 설명의 기계 번역 문장이 가장 많이 바뀌었어요.
- Mekanism·원자로 퀘스트 468키 중 296키를 다듬었어요. `반응기`를 `핵분열로`·`핵융합로`·`원자로`로,
  모듈 이름을 게임 속 `~ 기구`로 맞추고, 해요체·`당신`·`~하십시오`를 합쇼체로 고쳤어요.
- MoreMachine의 `~ 공장`을 본체와 같은 `~ 시스템`으로, 등급을 `오버클럭`·`다중 우주`로 통일했어요.
- 이름을 바로잡았어요: `액체 에텐`(에테인 오역), `과열된 나트륨`, 안료 색 이름, `레깅스`(각반),
  `메카슈트 하의`, `정제된 흑요석·발광석` 도구 16종, `HDPE 시트`(용지 오역), `화학적 투입 장치`,
  `유체 탱크`·`유체 방출기`, `스쿠버 마스크`, `차가운 걸음 기구`, `중력 조절 기구`.
- KubeJS 툴팁 `Increased Machine Boost!`를 `기계 성능 향상 효과 증가!`로 고쳤어요. 기초 전력 퀘스트의
  `에틸렌`도 Mekanism 이름 `에텐`으로 맞췄어요.

## 설치

1. Minecraft를 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.17_resourcepack.zip`을 압축 그대로 `resourcepacks/`에 넣어요.
3. `ATM10_Korean_8.1-stable.17_overrides.zip`의 `config/`와 `kubejs/`를 인스턴스 루트에 병합해요.
   퀘스트 문장과 KubeJS 툴팁이 바뀌었으므로 override도 함께 적용해야 해요.
4. 게임 언어를 한국어로 설정하고 새 팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요.

개인 설정은 포함하지 않으며 7.1 안정판은 그대로 유지해요.

## 검증 범위와 남은 표시

현재 JAR 영어 원문과 키 단위로 대조하고 자리표시자·색상 코드·줄바꿈·숫자 수를 검사해요. KubeJS는
문자열 밖 코드가 기준 커밋과 같은지와 `node --check`를 확인해요. 게임 내 화면은 아직 확인하지 않았어요.
[재검수 보고](../../versions/8.1/reports/quality_rereview_mekanism.md)를 참고하세요.
