# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.11

전체 번역 품질 재검수 2순위 **항상 보는 공통 UI**의 2부(지도·장신구·웨이스톤·나침반)를 다시
다듬었어요. stable.10까지의 모든 번역을 포함하며 ATM10 **8.1 / Minecraft 1.21.1**용이에요.
새 모드 번역은 없어요.

- JourneyMap, Curios, Waystones, Nature's Compass, Explorer's Compass 언어 2,644키를 영어 원문과
  다시 대조해 177키를 고치고 2,467키를 유지했어요.
- 새 용어 기준(엔티티·쿨타임·생물 군계·단축 바·키 지정)과 바닐라 이름(위치 표시 바, 정글나무)에
  맞췄어요.
- JourneyMap의 옵션·설정, 이름표·라벨, 관리자·OP처럼 섞여 있던 표기를 통일하고, 비문과 원문에서
  빠진 문장을 고쳤어요.
- Explorer's Compass 구조물 이름은 모드 안에서 크기 표기와 접미 형식을 맞췄어요.

## 설치

1. Minecraft를 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.11_resourcepack.zip`을 압축 그대로 `resourcepacks/`에 넣어요.
3. stable.10 override를 적용하지 않았다면 `ATM10_Korean_8.1-stable.11_overrides.zip`의
   `config/`와 `kubejs/`도 인스턴스 루트에 병합해요.
4. 게임 언어를 한국어로 설정하고 새 팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요.

이번 변경은 리소스팩 언어 파일만이에요. 개인 설정은 포함하지 않으며 7.1 안정판은 그대로 유지해요.

## 검증 범위와 남은 표시

현재 JAR 영어 원문과 키 단위로 대조하고 자리표시자·색상 코드·줄바꿈 수를 검사해요. 기준 커밋
대비 키 목록·순서가 그대로인지, 작업 원본(구조물 이름 파일 포함)과 산출물이 일치하는지 확인해요.
게임 내 화면은 아직 확인하지 않았어요.
[재검수 보고](../../versions/8.1/reports/quality_rereview_common_ui_2.md)를 참고하세요.
