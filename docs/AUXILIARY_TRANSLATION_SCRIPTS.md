# 보조 번역 스크립트: 제외 범위와 후속 검토

현재 상태: **기본 안정 배포에서 제외**. `7.1-stable.1`과 `8.1-stable.1`은 아래 네 파일에
실행 코드를 포함하지 않아요. 이 문서는 보조 번역을 자동으로 재도입하라는 작업 지시가 아니에요.
기본 배포 규칙은 `AGENTS.md`를 따라요.

## 보조 번역이 무엇인지

모드가 만든 화면·툴팁·채팅을 이벤트에서 읽고, 특정 영어 문구를 찾아 한국어로 교체하는
프로젝트 추가 코드예요. 언어 파일을 읽는 일반 번역과 달리 게임 실행 과정에 참여해요.
언어 키가 없는 하드코딩 문구를 번역하려고 추가했으며, 실제 모드 JAR은 바꾸지 않았어요.

번역 키가 있고 한국어만 없는 문구는 영어로 표시하도록 두었다가 한국어 키 값을 추가하면 돼요.
번역 키 자체가 없는 문구는 모드가 지원하는 다른 문서·데이터 경로가 있는지 먼저 확인하고,
그런 경로도 없다면 기본 안정판에서는 모드의 원래 표시를 유지해요.

## 기본 배포에서 비활성화한 파일

아래 경로는 **인스턴스 루트 기준**이에요. 두 ATM10 버전에 동일하게 적용해요.

| 파일 | 기존 보조 기능 | 제외 후 표시 |
|---|---|---|
| `kubejs/startup_scripts/appleskin_debug_labels.js` | AppleSkin F3 허기·포만도·소모도 줄 교체 | 해당 디버그 줄은 원래 표시 유지 |
| `kubejs/startup_scripts/mousetweaks_config_labels.js` | Mouse Tweaks 설정 화면의 버튼·선택지 교체 | 언어 키를 사용하지 않는 설정 문구는 원래 표시 유지 |
| `kubejs/startup_scripts/enderdrives_messages.js` | EnderDrives 시스템 채팅·명령 안내 교체 | 해당 채팅·명령 안내는 원래 표시 유지 |
| `kubejs/client_scripts/enderdrives_tooltips.js` | EnderDrives 동적 아이템 설명 교체 | 해당 동적 설명은 원래 표시 유지 |

이 모드들의 일반 아이템 이름·언어 키 번역은 계속 포함해요. FTB Quests, 가이드와 ATM10 원래
KubeJS의 표시 문구 번역도 유지해요. `NativeEvents`나 `Java.loadClass`가 있다는 이유만으로
ATM10 원래 스크립트까지 제거하지 않아요. 예를 들어 원래 banlist·hyperbox 동작은 유지해요.

## 기존 설치에서도 비활성화하는 방법

ZIP에서 네 파일을 단순히 제외하면 이전 설치의 실행 코드가 남아요. 따라서 override ZIP에는
같은 경로에 **주석만 있는 파일**을 넣어요. 기존 파일을 교체하면 변수·이벤트 등록·Java 호출이
없는 상태가 돼요. 파일명이 남는 것은 업데이트를 위한 의도적인 처리예요.

사용자는 Minecraft를 종료한 뒤 override를 인스턴스 루트에 병합하고 네 파일을 교체해요.
원하면 위 네 파일만 수동 삭제해도 보조 기능은 비활성화돼요. 다른 ATM10 스크립트는 지우지 않아요.
이전 코드를 다른 이름의 `.js`로 백업했다면 그 사본은 스크립트 폴더 밖에 보관해야 해요.
리소스팩 교체만으로는 설치된 KubeJS 코드가 바뀌지 않아요. 적용 후 완전히 재시작해요.
이번 작업에서는 사용자 요청에 따라 실제 인스턴스를 수정하지 않았어요.

## 확인된 오류와 검증의 한계

1. 블록 안의 const 선언: 양 버전 Rhino에서 재선언 오류가 발생했어요.
2. Mouse Tweaks의 블록 내 함수 선언: 이벤트 콜백에서 함수가 undefined였어요.
3. 화면의 getClass 호출: Rhino Java 래퍼에서 사용할 수 없어 시작 화면에서 충돌했어요.
4. EnderDrives의 정규식 replace: Java 문자열을 그대로 처리해 Java 메서드로 전달됐어요.
   툴팁 오류와 시스템 채팅 수신 중 연결 종료가 발생했어요.

Node.js 문법 검사는 Rhino 및 Minecraft의 Java 연동을 증명하지 못해요. Rhino로 실행해도
입력을 JavaScript 대역으로 만들면 실제 Java 문자열·컴포넌트와 달라 오류를 놓칠 수 있어요.
이전 검증에서 화면만 Java 객체로 바꾼 뒤에도 채팅과 동적 툴팁의 검증 공백이 남았어요.
과거 수정판의 검사 통과 기록을 전체 게임에서 정상 작동한다는 증거로 사용하지 않아요.

관련 기록: `versions/8.1/reports/startup_hotfix_release.md`,
`versions/8.1/reports/screen_crash_fix.md`. 보조 코드 원본은 `working/`의 AppleSkin,
Mouse Tweaks, EnderDrives 작업 폴더와 Git 이력에 검토 자료로 남겨요. 현재 배포용 코드가 아니에요.
`verify_startup_hotfix.py` 등 이전 보조 기능 검사는 현재 안정판을 검증하는 명령이 아니에요.

## 향후 다시 검토할 경우

2026-09-09 로드맵 정리: 사용자가 보조 코드 없는 안정판의 정상 작동을 확인했어요.
일반 신규 모드 번역과 기존 누락·퀘스트 품질 개선 뒤에 선택판을 검토해요.
[전체 순서](ATM10_VERSION_TRANSLATION_UPGRADE_PLAN.md)의 단계 5에 해당하며,
이번 요청은 계획 작성이에요. 구현·실제 적용을 시작한 것은 아니에요.

| 구현 순서 | 기능 | 우선순위 이유 | 실제 게임에서 반드시 확인할 동작 |
|---|---|---|---|
| 1 | EnderDrives 동적 툴팁 | 아이템 사용에 직접 도움, 특정 아이템으로 한정 가능 | 인벤토리·JEI hover, 값·색상 변경, 반복 표시 |
| 2 | Mouse Tweaks 설정 | 설정 내용을 이해하는 데 도움 | 대상 설정 열기·버튼 갱신·닫기, 다른 화면 영향 없음 |
| 3 | EnderDrives 시스템 채팅 | 연결 종료 이력이 있어 더 엄격한 확인 필요 | 관련 명령·메시지 수신·재접속, 무관한 메시지 원문 보존 |
| 4 | AppleSkin F3 정보 | 플레이 필수 정보보다 디버그용 정보 | F3 열기·닫기, 허기·포만도 값 갱신 |

사용자가 구현을 별도로 요청한 경우 다음 순서로 검토해요.

1. 현재 모드의 언어 키·리소스·퀘스트 등 기본 번역 경로를 다시 조사해요.
2. 보조 처리가 필요한 문구만 목록으로 만들고 특정 아이템·화면·메시지로 범위를 제한해요.
3. 한국어 문구를 가능한 한 리소스팩의 별도 키에 두고, 인식·교체 코드와 분리해요.
   자체 키를 만들어도 모드의 하드코딩 문구와 연결하는 코드는 여전히 필요해요.
4. Java와 JavaScript 자료형 경계를 명시하고, 교체 결과가 완성된 뒤에만 원문을 바꿔요.
5. 번역 실패 시 원문 유지와 예외 전파 차단을 설계해요. 모든 오류를 막는 보장으로 표현하지 않아요.
6. 실제 버전의 엔진·Java 객체로 일반 문구, 색상·수치·줄바꿈, 예상 밖 입력, 반복 호출과
   서버·클라이언트 조건을 검사하고 실제 게임에서 해당 동작을 확인해요.
7. 기본 배포와 분리한 선택 설치 자료로 제공할지 판단해요. 기존 코드 전체를 그대로 재포함하지 않아요.

### 선택판 구현·출시 조건

- 기본 번역 경로 재조사 → 특정 기능 하나 구현 → 실제 엔진·Java 객체 검사 → 게임 확인 →
  선택판 배포 순서예요. 다음 기능도 같은 단위를 반복해요.
- 전역 화면·모든 툴팁·모든 채팅의 무차별 치환을 피하고 대상 모드·객체·문구를 제한해요.
  임의 Java 클래스의 문자열 표현을 메시지로 취급하지 않아요.
- Java 문자열을 JavaScript 문자열로 변환하는 지점을 명시하고 실제 Rhino에서 검증해요.
  null·비문자열·서식·수치·예상 밖 메시지에 대한 처리와 원문 보존을 포함해요.
- 번역 실패 시 입력 이벤트를 취소하지 않고 원문을 유지해요. 콜백 예외의 전파를 막고,
  반복 오류 로그가 쌓이지 않도록 기능을 비활성화하는 복귀 방식을 검증해요.
  시작 시 등록·클래스 로딩 실패도 별도로 검사하며 단순 try/catch만으로 안전하다고 판단하지 않아요.
- 한국어 선택 때만 교체하고, 다른 언어·언어 전환·리소스팩 미설치 시 원래 문구를 유지해요.
  한국어를 별도 리소스팩 키로 제공해도 원문과 연결하는 코드는 여전히 필요해요.
- 클라이언트 전용 클래스가 전용 서버에서 로드되지 않도록 하고, 지원할 환경과 정확한
  모드/KubeJS/Rhino 버전을 기록해요. 8.1 검증을 7.1 검증으로 대신하지 않아요.
- 선택판은 기본 ZIP 두 개에 합치지 않아요. 설치·해제 방법, 동일 경로 덮어쓰기 순서를 안내해요.
  안정판 override를 다시 설치하면 보조 기능이 주석 파일로 비활성화된다는 점도 명시해요.
- 출시 조건은 해당 기능의 게임 동작과 원문 복귀까지 확인된 상태예요. 정적·대역 검사만
  통과했으면 선택판 실험 단계로 남기고 기본 안정 배포에 재포함하지 않아요.

## 현재 안정판 검사

`verify_stable_release.py`는 네 파일이 정해진 주석 내용과 정확히 같은지 확인하고, 기존 설치를
temp에서 재현해 덮어쓰기 후 실행 코드가 남지 않는지 검사해요. 이전 배포와 전체 파일 해시를
비교해 일반 번역·퀘스트·다른 KubeJS가 바뀌지 않았는지도 확인해요.
새 ZIP은 이 검사를 통과해야 해요. 8.1에서 변경 없는 배포 데이터는 이전 원문 호환 검증을
파일 해시 대조로 계승하며, 현재 실행 후 인스턴스와의 차이는 별도 감사 보고서로 남겨요.
