## 주요 교정

- 사망 메시지의 `%1$`를 현재 원문의 `%1$s`로 고치고 두 번째 인물 자리표시자도 보존했어요.
- 원문에 없는 `§b`·`§c` 색상 코드를 제거하고, 등급·행성·산소·중력·재료 용어를 통일했어요.
- Giselle Addon의 “기능”을 “업그레이드”로 고치고 장치·업그레이드·효과를 구분했어요.
- 가이드의 대쉬·칼코라이트·크라이오를 언어 파일의 데시·칼로라이트·극저온과 통일했어요.
- 달 환경 설명 위치에 귀환 설명이 들어 있던 후보, 오래된 로버 저장량, 빠진 슈트 비행 키와
  산소 누출·급격한 감압 안내를 현재 영어 기준으로 교정했어요.
- 내장 한국어 `oxygen_distributor.json`은 문자열 안의 잘못된 제어 문자 때문에 JSON 파싱이
  실패했어요. 오류를 `working/ad_astra/guide/source_errors.json`에 기록하고 후보를 사용하지 않았어요.
  새 리소스팩의 해당 파일은 현재 영어 구조와 정상 JSON으로 작성했어요. JAR은 수정하지 않았어요.
