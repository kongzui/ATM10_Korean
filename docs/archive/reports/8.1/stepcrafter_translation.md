## 연관 콘텐츠

현재 JAR에 별도 GuideME·Patchouli·Modonomicon 가이드가 없어요. 발전 과제 48파일은 색상별
제작법 해금용이며 `translate`, `subtitle`, 직접 `text` 표시 문구가 없어요.
`working/stepcrafter/jar_audit.json`에 전체 조사 목록을 보관해요.

색상별 관리자 블록은 Refined Storage의 `AbstractActiveColoredDirectionalBlock`을 상속해요.
그 클래스의 `getName`은 저장된 이름 컴포넌트를 반환하고, `BaseBlockItem.getName`도
블록의 이름을 사용해요. 원본 색상별 블록을 각각 다른 번역 키로 추측해서 추가하지 않아요.
설정은 현재 `ConfigImpl`에서 `text.autoconfig` 계열 번역 키를 만드는 경로를 확인했어요.

FTB Quests 1,000파일(현재 구조 66챕터), KubeJS 871파일에서 모드명·네임스페이스·
단계 제작기 관련 참조는 없어요. 관련 퀘스트 제목·Task·자동 제목·custom_name 또는
직접 표시 문구의 수정 대상이 없으므로 overrides는 바꾸지 않아요.
