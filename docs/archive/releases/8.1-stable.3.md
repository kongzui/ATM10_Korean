# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.3

Neo Vitae의 아이템·UI·툴팁·Modonomicon 가이드와 관련 퀘스트를 검수한 누적 배포예요.
Auroral을 포함한 기존 번역도 들어 있으므로 이전 번역팩을 먼저 설치할 필요는 없어요.
ATM10 **8.1 / Minecraft 1.21.1**용이며 7.1 안정판은 그대로 유지해요.

## 설치

1. Minecraft를 완전히 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.3_overrides.zip`을 풀어 내부 `config/`와 `kubejs/`를
   ATM10 8.1 인스턴스 루트에 병합하고 같은 이름의 파일을 교체해요.
3. `ATM10_Korean_8.1-stable.3_resourcepack.zip`은 압축을 풀지 않고 `resourcepacks/`에 넣어요.
4. 게임 언어를 한국어로 설정하고 새 리소스팩만 활성화해요. 이전 폴더팩·ZIP은 비활성화해요.
5. 게임을 완전히 다시 시작해요. 개인 단축키·그래픽 설정은 포함하지 않아요.

override에는 예전 보조 기능 네 개를 끄는 주석 전용 파일도 들어 있어요.
리소스팩만 교체하면 예전 보조 코드가 남을 수 있으므로 두 ZIP을 함께 사용해요.
[보조 번역 제외 범위](../../AUXILIARY_TRANSLATION_SCRIPTS.md)는 이전 안정판과 같아요.

## 추가한 번역

- 현재 Neo Vitae JAR 영어 3,053키 전체: 새 한국어 2,953키, 고유명사·단위 표기 유지 100키예요.
  이전 배포의 Neo Vitae 일반 언어 재사용은 0키이며 JAR에도 한국어 후보가 없어요.
- 위 언어에는 `book.*` 1,531키가 포함돼요. 책 JSON 223개가 참조하는 고유 언어 키는
  1,529개이며, 일반 언어와 별도 번역 수로 중복 합산하지 않아요.
- 책 JSON에 직접 적힌 표시 문구 61개도 처리했어요. 한국어 49개와 라틴어 이름 유지 12개예요.
  현재 로더가 문자열 전체를 언어 키로 조회하는 경로를 이용하므로 추가 실행 코드가 없어요.
  최종 Neo Vitae 언어 파일은 총 3,114키예요.
- 기존 퀘스트 105키를 영어와 대조해 66키의 용어·제목을 고치고 39키는 그대로 재사용해요.
  퀘스트 구조·Task 요구량·진행 조건은 바꾸지 않아요.
- KubeJS의 관련 항목은 Teleposer 제작법의 아이템 ID 참조였으며, 추가 표시 문구 변경은 없어요.
- Auroral 언어 148키·GuideME 29페이지·퀘스트 46키도 누적 포함돼요.

## 검증과 확인 범위

현재 JAR 영어 전체, 직접 표시 문구의 JSON 위치, 책의 언어 참조, Modonomicon 로더 근거,
퀘스트 영어·구조·한국어를 대조해요. 숫자·자리표시자·개행·색상·링크·태그·이스케이프를 검사해요.
전체 JSON/SNBT/JS 문법과 보조 코드 부재, 변경 없는 기존 파일의 고정 해시도 검사해요.
ZIP의 루트·목록·CRC와 각 내부 파일이 검증본과 같은지 확인해요.

실제 게임 인스턴스에는 적용하지 않았어요. 사용자 설치 후 JEI 검색·툴팁, 모드 UI,
책의 모든 카테고리·직접 표시 문구, Neo Vitae 퀘스트 제목과 Task를 화면에서 확인해야 해요.
정적 표시 경로 검증을 실제 게임 화면 확인으로 기록하지 않아요.

원문에는 절삭유 속도 25%%/50%%처럼 페이지 간 설명 차이와 과거 아이템 이름이 있어요.
수치를 추정해서 고치지 않았으며, 판단 근거는
[Neo Vitae 완료 보고](../reports/8.1/neovitae_completion.md)에 기록해요.
다른 신규 모드와 기존 누락 번역은 로드맵 단계 2 이후의 별도 작업이에요.

## 다시 검증하고 ZIP 만들기

```powershell
python scripts/verify_stable_release.py --version 8.1
python scripts/package_compat_release.py --version 8.1
```

검증 보고서는 `versions/8.1/reports/8.1-stable.3_stable_validation.json`, ZIP 목록은
`versions/8.1/manifests/8.1-stable.3_packages.json`에 보존해요.
배포 파일은 `temp/releases/8.1-stable.3/`의 ZIP 두 개예요.
