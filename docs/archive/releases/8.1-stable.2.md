# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.2

Auroral의 일반 언어 148키를 검수하고 GuideME 29페이지와 관련 퀘스트의 아이템 이름을 맞춘 누적 배포예요.
ATM10 **8.1 / Minecraft 1.21.1**용이며 이전 번역팩을 먼저 설치할 필요는 없어요.
7.1 안정판과 기존 보조 코드 제외 방침은 유지해요.

## 설치

1. Minecraft를 완전히 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.2_overrides.zip`을 풀어 내부 `config/`와 `kubejs/`를
   ATM10 8.1 인스턴스 루트에 병합하고 같은 이름의 파일을 교체해요.
3. `ATM10_Korean_8.1-stable.2_resourcepack.zip`은 압축을 풀지 않고 `resourcepacks/`에 넣어요.
4. 게임 언어를 한국어로 설정하고 새 리소스팩만 활성화해요. 이전 폴더팩·ZIP은 비활성화해요.
5. 게임을 완전히 다시 시작해요. 개인 단축키·그래픽 설정은 이 ZIP에 포함되지 않아요.

override에는 예전 보조 기능 네 개를 끄는 주석 전용 파일도 들어 있어요.
리소스팩만 교체하면 예전 보조 코드가 남을 수 있으므로 두 ZIP을 함께 사용해요.
자세한 제외 범위는 [보조 번역 안내](../../AUXILIARY_TRANSLATION_SCRIPTS.md)를 확인해요.

## 추가한 번역

- Auroral JAR `auroral-1.21.1-1.1.1.jar`의 영어 148키를 전부 검수했어요.
- 신규 한국어 146키와 공식 모드명 그대로 유지한 2키예요. 기존 일반 언어 재사용은 0키예요.
- 아이템·블록·장비·발전 과제·설정·툴팁·자막과 JEI·Jade 문구를 포함해요.
- 이미 번역된 Auroral 퀘스트 46키 중 34키의 용어·제목을 맞추고 나머지 12키는 유지해요.
  퀘스트 구조와 진행 조건은 바꾸지 않아요.
- GuideME 29페이지를 번역하고 태그·링크·개행·숫자와 한국어 리소스 탐색 경로를 확인했어요.

## 검증과 확인 범위

현재 JAR 영어 전체와 검수 기록, 변경한 퀘스트의 현재 영어·구조·한국어를 대조해요.
변경하지 않은 기존 번역만 stable.1의 검증 해시를 계승해요. 전체 JSON/SNBT/JS 문법,
중복 키·자료형·자리표시자·숫자·줄바꿈·서식, 보조 코드 부재와 ZIP 루트·CRC·내용을 검사해요.

실제 인스턴스는 수정하지 않아요. 게임 화면에서 새 번역이 표시되는지는 사용자 설치 후 확인해요.
확인할 화면은 JEI 아이템 검색·툴팁, Auroral 퀘스트 제목과 Task, 빙하 대야의 Jade/JEI 안내, GuideME 책 29페이지예요.
기존 안정판의 정상 작동 확인을 이번 새 번역의 화면 확인으로 대신하지 않아요.

## 다시 검증하고 ZIP 만들기

```powershell
python scripts/verify_stable_release.py --version 8.1
python scripts/package_compat_release.py --version 8.1
```

이 명령은 현재 `output/8.1/release.json`의 배포를 검증하고 포장해요. 이 배포 시점의 결과는
`versions/8.1/reports/8.1-stable.2_stable_validation.json`, ZIP 목록은
`versions/8.1/manifests/8.1-stable.2_packages.json`에 보존해요.
파일은 `temp/releases/8.1-stable.2/`에서 제공해요. Neo Vitae는 다음 누적 배포에 포함해요.
