# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.16

전체 번역 품질 재검수 7순위 **Applied Energistics 2와 애드온**을 반영했어요. stable.15까지의 모든
번역을 포함하며 ATM10 **8.1 / Minecraft 1.21.1**용이에요. 새 모드 번역은 없어요.

- AE2 본체와 Extended AE, Advanced AE, MEGA Cells, Applied Flux 등 17개 모드 언어 2,099키를 영어
  원문과 다시 대조해 42키를 고치고 2,057키를 유지했어요.
- AE2·Extended AE·Advanced AE 퀘스트 266키 중 24키를 다듬었어요.
- GuideME 가이드 223파일을 다시 읽어 129파일에서 문장 263곳을 고쳤어요. `조합법`을 `제작법`으로,
  `제작 격자`를 `제작 칸`으로 통일하고, `<ItemLink>` 뒤 조사를 실제 이름에 맞췄어요.
- MEGA Cells의 `하늘 강철·청동·오스뮴`을 용어집 `천령 ~`으로 바꾸고, 같은 이름의 압축 블록 27키도
  함께 맞췄어요.
- 월드·파티션·허용 목록·차단 목록·제거 업그레이드·크리에이티브 비행 같은 용어집 표기와 해요체·번역투를
  바로잡았어요.

## 설치

1. Minecraft를 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.16_resourcepack.zip`을 압축 그대로 `resourcepacks/`에 넣어요.
3. `ATM10_Korean_8.1-stable.16_overrides.zip`의 `config/`와 `kubejs/`를 인스턴스 루트에 병합해요.
   퀘스트 문장이 바뀌었으므로 override도 함께 적용해야 해요.
4. 게임 언어를 한국어로 설정하고 새 팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요.

개인 설정은 포함하지 않으며 7.1 안정판은 그대로 유지해요.

## 검증 범위와 남은 표시

현재 JAR 영어 원문과 키 단위로 대조하고 자리표시자·색상 코드·줄바꿈 수를 검사해요. 가이드는 기준 커밋
대비 태그·인라인 코드·링크·이미지·제목 단계·숫자·front matter가 그대로인지 검사해요. 게임 내 화면은
아직 확인하지 않았어요. [재검수 보고](../../../versions/8.1/reports/quality_rereview_ae2.md)를 참고하세요.
