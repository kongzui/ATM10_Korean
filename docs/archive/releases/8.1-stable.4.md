# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.4

Ad Astra와 Giselle Addon의 일반 언어, Astrodux 가이드를 추가한 누적 배포예요.
Auroral·Neo Vitae와 기존 번역도 포함해요. ATM10 **8.1 / Minecraft 1.21.1**용이에요.
7.1 안정판은 바꾸지 않았어요.

## 설치

1. Minecraft를 완전히 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.4_overrides.zip` 안의 `config/`와 `kubejs/`를
   ATM10 8.1 인스턴스 루트에 병합해요.
3. `ATM10_Korean_8.1-stable.4_resourcepack.zip`은 압축을 풀지 않고 `resourcepacks/`에 넣어요.
4. 게임 언어를 한국어로 설정하고 새 리소스팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요. 개인 단축키·그래픽 설정은 포함하지 않아요.

이번 배포의 override 내용은 stable.3과 같아요. 처음 설치하거나 오래된 보조 코드가 남아 있다면
두 ZIP을 함께 사용하세요. 보조 번역 실행 코드는 계속 제외하며, 기존 네 파일은 주석 전용이에요.

## 추가한 번역

| 범위 | 전체 | 현재 JAR 한국어 재사용 | 기존 후보 교정 | 새 한국어 | 원문 표기 유지 |
|---|---:|---:|---:|---:|---:|
| Ad Astra 일반 언어 | 831 | 334 | 80 | 387 | 30 |
| Giselle Addon 일반 언어 | 168 | 87 | 75 | 6 | 0 |
| Astrodux 가이드 표시 문구 | 165 | 42 | 56 | 65 | 2 |

가이드는 카테고리 4파일과 항목 31파일, 본문 페이지 99개예요. 일반 언어와 가이드의 표시 문구는
서로 별개로 집계해요. 프로젝트의 이전 배포에는 이 계열의 일반 언어·전용 가이드 산출물이 없었어요.

- 사망 메시지의 잘못된 자리표시자와 불필요한 색상 코드를 현재 영어에 맞췄어요.
- 애드온의 `Upgrade`를 업그레이드로 고치고, 산소·중력·재료 이름을 본체와 통일했어요.
- 가이드는 현재 영어의 구조로 작성했어요. 내장 한국어의 페이지 이동·누락·오래된 수치를 교정하고,
  `oxygen_distributor.json`의 문법 오류가 새 리소스팩 가이드에 이어지지 않도록 했어요.
- 현재 퀘스트 구조 66챕터에 관련 참조가 없어요. 다른 언어에 남은 오래된 챕터 제목은 수정하지 않아요.
- KubeJS의 Astrodux 제작법과 금성 사암 태그는 식별자 참조뿐이므로 수정하지 않았어요.

## 검증과 확인 범위

현재 두 JAR의 해시·영어 전체, JSON 중복·자료형·키·자리표시자·숫자·개행·서식·링크를 검증해요.
가이드의 제작법·아이콘·페이지 구조·식별자는 영어와 동일하며 `use_resource_pack` 경로를 확인했어요.
발전 과제·소리 자막·마법부여의 언어 참조 70개를 확인했어요.

누적 배포 검증은 기존 Auroral·Neo Vitae 검증과 변경 없는 파일의 고정 해시 검사를 유지하면서
이번 계열의 현재 원문 검증을 추가해요. 전체 JSON/SNBT/JS 문법, 보조 코드 부재, ZIP 루트·CRC·내용을
검증해요. 실제 게임 화면은 확인하지 않았어요.

설치 후 JEI 이름·툴팁, 장비·기계 화면, Astrodux의 네 카테고리와 99페이지, 애드온 업그레이드를
게임에서 확인해야 해요. 원문의 일반 진행 설명과 실제 ATM10 제작법 차이는 번역으로 임의 변경하지 않아요.

## 재검증과 ZIP 생성

```powershell
python scripts/verify_ad_astra_translation.py
python scripts/verify_stable_release.py --version 8.1
python scripts/package_compat_release.py --version 8.1
```

검증 보고서는 `versions/8.1/reports/8.1-stable.4_stable_validation.json`, ZIP 목록은
`versions/8.1/manifests/8.1-stable.4_packages.json`에 저장해요.
배포 파일은 `temp/releases/8.1-stable.4/`의 ZIP 두 개예요.
이 기기의 선택 파일 적용 결과는 `versions/8.1/reports/ad_astra_apply.json`으로 구분해요.
