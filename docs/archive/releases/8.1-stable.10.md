# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.10

2026-09-29에 정한 용어 기준을 품질 재검수를 마친 1순위(팩 공통 진행 퀘스트)와 2순위 1부
(JEI·Jade·FTB 공통 UI)에 반영했어요. stable.9까지의 모든 번역을 포함하며 ATM10 **8.1 /
Minecraft 1.21.1**용이에요. 새 모드 번역은 없어요.

- 몹이 나타나는 뜻의 `생성` → `스폰`, `개체` → `엔티티`, `재사용 대기시간` → `쿨타임`
- `생물군계` → `생물 군계`, `단축바` → `단축 바`, `키 설정` → `키 지정`(바닐라 표기)
- 낯선 관용구 `키친싱크 모드팩` → `온갖 모드를 담은 모드팩`
- 광석·구조물이 만들어지는 `생성`, `생성 알`·`시련 생성기` 같은 바닐라 이름과 문장 속
  `순간이동`은 그대로 뒀어요.
- 퀘스트 34키, 언어 68키, KubeJS 툴팁 3줄을 고쳤어요.

## 설치

1. Minecraft를 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.10_overrides.zip`의 `config/`와 `kubejs/`를 인스턴스 루트에 병합해요.
3. `ATM10_Korean_8.1-stable.10_resourcepack.zip`을 압축 그대로 `resourcepacks/`에 넣어요.
4. 게임 언어를 한국어로 설정하고 새 팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요.

퀘스트와 KubeJS도 바뀌었으므로 override ZIP도 함께 적용해야 해요. 개인 설정은 포함하지 않으며
7.1 안정판은 그대로 유지해요.

## 검증 범위와 남은 표시

재검수 계열 검증으로 키 목록, 자리표시자, 색상 코드, 숫자와 줄바꿈을 확인하고 KubeJS는 문자열
밖 코드가 그대로인지와 문법을 확인해요. Ender IO의 `솔라리움`은 아이템 이름과 함께 바꿔야 해서
Ender IO 계열 재검수 때 고쳐요. 게임 내 화면은 아직 확인하지 않았어요.
[용어 교체 보고](../../../versions/8.1/reports/quality_rereview_term_pass.md)를 참고하세요.
