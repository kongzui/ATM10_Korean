# ATM10 8.1 한국어 누적 안정판 · 8.1-stable.13

전체 번역 품질 재검수 4순위 **인벤토리·정보·가이드 UI**를 다시 다듬었어요. stable.12까지의 모든
번역을 포함하며 ATM10 **8.1 / Minecraft 1.21.1**용이에요. 새 모드 번역은 없어요.

- Corail Tombstone, Lootr, Tempad, Enchantment Descriptions, AppleSkin, Patchouli 등 20개 모드
  언어 2,443키를 영어 원문과 다시 대조해 210키를 고치고 2,233키를 유지했어요.
- 리스폰·엔티티·쿨타임·생물 군계·단축 바·켜면 같은 용어집 표기와 바닐라 이름(팬텀, 차광 유리,
  네더라이트 파편, 철 원석, 레드스톤 조명, 속도 감소)에 맞췄어요.
- Tempad는 공식 표기 `Tempad`로, 앱·업그레이드 이름 속 Teleport는 `텔레포트`로 정리했어요.
- `당신`, `이러한`, `성공적으로 ~되었습니다`, `~하십시오` 같은 번역투와 누락된 조건·주어를 고쳤어요.

## 설치

1. Minecraft를 종료하고 덮어쓸 파일을 백업해요.
2. `ATM10_Korean_8.1-stable.13_resourcepack.zip`을 압축 그대로 `resourcepacks/`에 넣어요.
3. stable.10 이후 override를 적용하지 않았다면 `ATM10_Korean_8.1-stable.13_overrides.zip`의
   `config/`와 `kubejs/`도 인스턴스 루트에 병합해요.
4. 게임 언어를 한국어로 설정하고 새 팩을 활성화해요. 이전 번역 ZIP·폴더팩은 비활성화해요.
5. 게임을 완전히 다시 시작해요.

이번 변경은 리소스팩 언어 파일만이에요. 개인 설정은 포함하지 않으며 7.1 안정판은 그대로 유지해요.

## 검증 범위와 남은 표시

현재 JAR 영어 원문과 키 단위로 대조하고 자리표시자·색상 코드·줄바꿈 수를 검사해요. 기준 커밋
대비 키 목록·순서가 그대로인지, 작업 원본과 산출물이 일치하는지 확인해요. 게임 내 화면은 아직
확인하지 않았어요. [재검수 보고](../../../versions/8.1/reports/quality_rereview_info_ui.md)를 참고하세요.

## 재검증과 ZIP 생성

```powershell
python scripts/quality_rereview_lang.py info_ui
python scripts/verify_quality_rereview.py
python scripts/verify_stable_release.py --version 8.1
python scripts/package_compat_release.py --version 8.1
```

`versions/8.1/manifests/8.1-stable.13_packages.json`이에요.
배포 파일은 `temp/releases/8.1-stable.13/`의 ZIP 두 개예요.
