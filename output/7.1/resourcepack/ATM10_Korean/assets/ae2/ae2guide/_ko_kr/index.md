# Applied Energistics 2란?

# 이 가이드 사용법

* 왼쪽 사이드바를 열면 목차를 볼 수 있습니다.
* 여러 페이지에는 조작할 수 있는 장면이 있습니다. 장면 옆에 ![확대](assets/diagrams/plus.png)와
![축소](assets/diagrams/minus.png) 버튼이 있다면 카메라를 회전하거나 이동할 수 있습니다.
마우스 왼쪽 버튼을 누른 채 드래그하면 회전하고, 오른쪽 버튼을 누른 채 드래그하면 이동합니다.

# Applied Energistics 2란?

Applied Energistics 2는 물류와 저장 문제를 해결하는 여러 부품과 시스템을 추가합니다. 상자로 가득한
거대한 방을 작은 ME 네트워크로 바꿀 수 있지만, 이는 시작에 불과합니다.
Applied Energistics 2는 모드팩의 다른 모드와 연동하고 자동화할 수 있도록 설계되었습니다. 한 번의
클릭으로 복잡한 제작 과정의 모든 재료와 최종 결과물을 제작하거나, 필요한 수량을 항상 비축하도록
부족할 때마다 추가로 제작하거나, 기지 곳곳으로 아이템을 운반하는 시스템을 만들 수 있습니다.
