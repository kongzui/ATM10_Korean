# 메모리 카드

<ItemImage id="memory_card" scale="4" />

메모리 카드는 AE2 [장치](../ae2-mechanics/devices.md) 사이에서 설정을 복사해 붙여 넣고,
[P2P 터널](p2p_tunnels.md)을 연결하는 데 사용됩니다. [업그레이드 카드](upgrade_cards.md)를 장치에 붙여 넣을 수도 있습니다.

- Shift+우클릭하면 설정을 복사하거나 새 P2P 연결 주파수를 생성합니다.
- 우클릭하면 설정, 업그레이드 카드 또는 연결 주파수를 붙여 넣습니다.
