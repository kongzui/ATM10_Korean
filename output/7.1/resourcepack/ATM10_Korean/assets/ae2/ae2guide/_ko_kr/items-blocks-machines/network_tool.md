# 네트워크 도구

<ItemImage id="network_tool" scale="4" />

네트워크 도구는 [렌치](wrench.md)를 개조한 도구로, 네트워크 진단 정보를 표시하고 [업그레이드 카드](upgrade_cards.md)를 보관할 수 있습니다.
렌치처럼 빠르게 장치를 해체하고 케이블에서 [부품](../ae2-mechanics/cable-subparts.md)을 떼어낼 수 있지만,
장치를 회전할 수는 없습니다.

[업그레이드 카드](upgrade_cards.md)를 보관하는 슬롯 9개가 있습니다. 도구가 인벤토리 어디에 있든 모든 AE2 장치 UI에서
이 카드를 사용할 수 있습니다.

네트워크의 어느 부분이든 우클릭하면 <ItemLink id="controller" />를 우클릭했을 때와 비슷한 진단 정보 창이 열립니다.
이 창에는 다음 정보가 표시됩니다.

*   네트워크에서 사용 중인 채널 수
*   에너지를 AE 또는 E/FE로 표시하는 전역 설정 전환 버튼
*   네트워크에 저장된 [에너지](../ae2-mechanics/energy.md) 양과 네트워크의 최대 에너지 용량
*   네트워크로 들어오는 에너지와 네트워크가 사용하는 에너지 양
*   네트워크의 모든 [장치](../ae2-mechanics/devices.md)와 부품 목록

[서브네트워크](../ae2-mechanics/subnetworks.md)를 구성할 때 서로 다른 두 케이블이나 장치가 같은 네트워크에 속하는지 확인하는 데도 유용합니다.

## 덮개 숨기기

어느 손이든 네트워크 도구를 들고 있으면 <a href="facades.md">덮개</a>가 숨겨집니다.

덮개를 먼저 제거하지 않고도 숨겨진 덮개 뒤의 블록과 상호작용할 수 있습니다.
