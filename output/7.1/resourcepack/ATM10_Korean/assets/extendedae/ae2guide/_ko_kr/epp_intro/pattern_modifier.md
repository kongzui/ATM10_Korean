# 패턴 수정기

패턴 수정기는 패턴을 한꺼번에 수정하는 도구입니다.

<ItemImage id="extendedae:pattern_modifier" scale="4"></ItemImage>

오른쪽 클릭하면 GUI가 열립니다.

## 배수 모드

해당 버튼을 클릭하면 처리 패턴의 입력 및 출력 수량을 X배로 만들거나 X로 나눌 수 있습니다.

![패턴 수정기](../pic/pm.png)

원본 패턴:

![원본 패턴](../pic/pm1.png)

10배 적용 후:

![적용 후 패턴](../pic/pm2.png)

지우기 버튼을 클릭하면 모든 패턴의 내용을 지워 빈 패턴으로 만들 수도 있습니다.

### 참고:

 - 나누기 버튼은 수량이 나누어떨어질 때만 작동합니다. 예를 들어 패턴의 입력으로 조약돌 3개가 필요하면 ÷2 버튼은 작동하지 않습니다. 3÷2는 1.5이기 때문입니다.

 - 곱하기 버튼의 수량 상한은 999,999입니다. 단일 재료의 수량을 이보다 크게 만들 수 없습니다.

## 교체 모드

패턴의 특정 입력 및 출력 재료를 다른 아이템으로 교체합니다.

![교체 모드](../pic/pm4.png)

슬롯 A에는 교체할 재료를, 슬롯 B에는 새로 사용할 재료를 넣습니다.

예를 들어 다음 설정은 판자를 석탄으로 교체합니다.

![교체 전](../pic/pm6.png)

![교체 설정](../pic/pm5.png)

교체 버튼을 클릭하면 교체를 실행합니다.

![교체 후](../pic/pm7.png)
