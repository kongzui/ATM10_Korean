# 무선 범용 터미널

<ItemImage id="ae2wtlib:wireless_universal_terminal" scale="3" />

<ItemLink id="ae2wtlib:wireless_universal_terminal" />은 여러 [무선 터미널](wireless_terminals.md)을 하나의 아이템으로 합친 것입니다.

모든 [AE2WTLib 무선 터미널](wireless_terminals.md)을 하나의 터미널로 합칠 수 있습니다.

AE2의 <ItemLink id="ae2:wireless_terminal" />은 <ItemLink id="ae2wtlib:wireless_universal_terminal" />에 ***합칠 수 없습니다***.


## UI

<ItemLink id="ae2wtlib:wireless_universal_terminal" />은 터미널 UI에 버튼을 추가합니다.
버튼을 왼클릭하면 다음 [무선 터미널](wireless_terminals.md)로, 우클릭하면 이전 터미널로 전환합니다.


## 업그레이드

<ItemLink id="ae2wtlib:wireless_universal_terminal" />은 설치된 [무선 터미널](wireless_terminals.md)과 같은 업그레이드를 지원합니다.
설치한 터미널 하나마다 업그레이드 슬롯이 2개 추가됩니다.

## 에너지 저장량

터미널을 추가하면 각 터미널의 에너지 저장량이 합쳐집니다.
따라서 터미널 두 개를 넣은 <ItemLink id="ae2wtlib:wireless_universal_terminal" />의 에너지 저장량은 [무선 터미널](wireless_terminals.md)의 두 배입니다.
