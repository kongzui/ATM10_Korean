# 상단 영역

![노드 화면 상단 — 표시 전환, 네트워크 이름, 변경 버튼, 채널 선택기, 이름표 설정](images/header-full.png)

노드 설정 화면의 맨 위 부분이에요. 월드에서 노드를 표시하는 방식, 소속 네트워크, 현재 편집할 9개 채널 중 하나를 정해요.

## 표시됨

![표시 전환 버튼](images/header-visible.png)

**기능:** 월드에서 노드를 어떻게 표시할지 정하는 전환 버튼이에요.

**동작:**

- **표시됨**(기본값): 렌치를 들고 있는지와 관계없이 노드를 **항상** 완전히 불투명하게 표시해요.
- **숨겨짐**: 평소에는 노드를 표시하지 **않아요**. 렌치를 들었을 때만 약 삼분의 일 불투명도로 나타나므로 보고 클릭할 수 있어요.

표시 여부는 겉모습에만 영향을 줘요. 숨긴 노드도 같은 방식으로 자원을 전송해요.

**바꾸는 방법:** 버튼을 좌클릭하세요. 글자가 **표시됨**과 **숨겨짐** 사이에서 바뀌며 즉시 적용돼요. 컴퓨터의 노드 표에서 **표시** / **숨기기** 버튼으로 네트워크의 모든 노드를 한꺼번에 전환할 수도 있어요.

설비를 완성하면 숨겨서 깔끔하게 정리하고, 다시 찾아야 할 때 렌치를 꺼내세요.

## 네트워크

![네트워크 이름 표시](images/header-network-pill.png)

**기능:** 상단 가운데의 초록색 표시예요. 현재 노드가 소속된 네트워크 이름을 보여 줘요.

**동작:** 현재 네트워크 이름을 표시해요. 새로 만든 네트워크의 기본 이름은 **Network**이므로 "Network"라면 기본 이름을 쓰는 네트워크예요. 다른 글자라면 이름을 바꾼 거예요.

**바꾸는 방법:** 이름 표시는 버튼이 아니에요. 노드를 다른 네트워크로 옮기려면 옆의 **변경** 버튼을 사용하세요.

네트워크를 지정하지 않은 노드는 아무것도 하지 않아요. 네트워크를 고를 때까지 9개 채널이 모두 멈춰 있어요.

## 변경

![변경 버튼](images/header-change.png)

**기능:** 네트워크 이름 오른쪽의 버튼이에요.

**동작:** 네트워크 선택 화면을 열어요. 여기에서 다음 작업을 할 수 있어요.

- 소유한 기존 네트워크를 골라 노드를 옮겨요.
- 최대 32자의 새 이름을 입력해 네트워크를 만들고 참가해요.
- 현재 네트워크를 떠나 미지정 상태로 만들어요.

**네트워크를 바꾸는 방법:** **변경**을 누른 뒤 목록에서 고르거나 새 이름을 입력하고 확인하세요. 노드가 즉시 옮겨지고 채널 설정 화면으로 돌아와요.

설비를 여러 네트워크로 나누거나, 여러 노드를 하나의 네트워크로 합치거나, 노드가 속한 네트워크 이름을 바꿀 때 사용하세요.

## 채널 선택기

![채널 선택 행 (0–8)](images/header-channels.png)

**기능:** **0**부터 **8**까지 번호가 붙은 아홉 버튼이에요. 노드의 9개 채널을 나타내요.

**동작:** 아래 설정 패널에서 열어 볼 채널을 골라요. 상태, 모드, 유형, 필터는 여기서 선택한 채널에 적용돼요. 업그레이드는 노드 전체에 적용돼요.

**표시 의미:**

- 번호 둘레의 **빨간 테두리** = 현재 선택하여 편집 중인 채널이에요.
- 번호 옆의 **초록 점** = 채널 상태가 꺼짐이 아니며, 켜져 작동 중이에요.
- 테두리와 점이 모두 없음 = 채널은 있지만 꺼져 있고 선택되지 않았어요.

켜진 9개 채널은 모두 동시에 작동해요. 선택기는 *작동할* 채널이 아니라 *살펴볼* 채널을 정해요.

**채널을 바꾸는 방법:**

- 번호를 **한 번 클릭**하면 선택돼요. 아래 설정이 해당 채널의 설정으로 바뀌어요.
- 이미 선택한 번호를 **두 번 클릭**하면 이름을 바꿔요. 최대 24자의 이름을 입력한 뒤 Enter로 저장하거나 바깥을 눌러 취소하세요.

**채널 이름:** 노드 이름표와 별개로 채널마다 짧은 이름을 정할 수 있어요. 채널 버튼 위에 마우스를 올렸을 때만 툴팁으로 표시돼요. 이름이 없으면 두 번 클릭하여 지정하라는 안내가 나와요.

이름은 표시용이며 전송에 영향을 주지 않아요. `in`, `out`, `fuel`, `buffer`, `overflow`처럼 용도를 적어 두면 나중에 다시 보아도 무엇을 하는 채널인지 알기 쉬워요.

## 이름표 설정

![이름표 설정 버튼](images/header-set-label.png)

**기능:** 채널 선택 행 아래의 버튼이에요.

**동작:** 노드 전체에 이름표를 지정해요. 네트워크 이름이나 채널 이름과는 별개예요. 같은 노드들을 묶어 채널 설정을 동기화하는 데 사용해요.

**바꾸는 방법:** **이름표 설정**을 누르면 현재 네트워크에서 사용하는 이름표 목록과 입력란이 열려요. 다음 중 하나를 하세요.

- 목록에서 기존 이름표를 골라 그 그룹에 참가해요.
- 최대 48자의 새 이름표를 입력하고 Enter를 눌러 그룹을 만들어요.

입력란을 비운 채 확인하면 이름표를 지워요.

**사용하는 이유:** 같은 네트워크의 둘 이상의 노드가 이름표를 공유하면 하나의 변경사항이 나머지 모두에 자동 복사돼요. 채널 모드, 유형, 필터, 전송량, 지연, 필터 아이템과 필터 설정이 포함돼요. 업그레이드는 노드마다 따로 유지되며 전송량은 각 노드의 업그레이드 한도로 제한돼요.

예를 들어 화로 노드 20개에 `furnace` 이름표를 붙이면, 하나만 설정해도 나머지 19개가 자동으로 따라 해요. 나중에 어느 하나를 바꿔도 전체에 반영돼요.

컴퓨터의 노드 표도 이름표별로 묶어서 보여 주므로 쉽게 찾아볼 수 있어요.
