# 컴퓨터

컴퓨터는 물류 네트워크를 살펴보고 관리하는 터미널 화면을 제공하는 설치형 블록이에요. 기지에 놓고 우클릭하면 모든 네트워크 목록, 활성 채널의 실시간 전송량, 노드 설정 바로 열기, 노드 표시 여부 일괄 전환을 사용할 수 있어요.

![네트워크 관리자 — 연결된 네트워크가 없는 대기 화면](images/network-manager-idle.png)

## 컴퓨터 열기

설치한 컴퓨터 블록을 우클릭하면 **네트워크 관리자** 화면이 열려요. 보관함에 [렌치](../wrench/index.md)가 있으면 컴퓨터가 오른쪽 위 드라이브 슬롯에 하나를 **자동으로 넣어요**. 렌치는 소모되지 않아요. 화면을 닫아도 직접 꺼낼 때까지 컴퓨터에 남아 있어요.

드라이브 슬롯은 네트워크 목록 화면에서만 조작할 수 있어요. 입출력 모니터나 노드 표로 이동했다면 목록으로 돌아와야 렌치 슬롯을 만질 수 있어요.

## 세 가지 하위 시스템

목록에서 네트워크를 고르면 두 가지 하위 시스템 중 하나로 이동할 수 있어요. 각각의 페이지에서 자세히 설명해요.

- [네트워크 목록](network-directory.md) — 왼쪽의 네트워크 목록이에요. 검색, 고정, 네트워크 연결을 해요.
- [입출력 모니터](io-monitor.md) — 채널별 전송량을 실시간 그래프로 보여 줘요. 채널당 측정값 120개를 표시해요.
- [노드 표](node-table.md) — 연결한 네트워크의 모든 노드를 이름표별로 묶어서 보여 주며, 각 행에서 작업할 수 있어요.

네트워크에 연결하기 전에는 오른쪽에 **연결된 네트워크 없음**이 표시돼요. 목록에서 하나를 고르면 하위 시스템 버튼이 활성화돼요.

## 즐겨찾는 네트워크

목록의 각 네트워크 항목 오른쪽에는 작은 **별** 아이콘이 있어요. 누르면 목록 위에 고정돼요. 고정된 네트워크가 먼저 나오고 나머지가 뒤따라요. 별 표시 상태는 컴퓨터 블록 자체에 저장되어 게임을 다시 켜도 유지돼요. 컴퓨터마다 즐겨찾기를 다르게 정할 수 있어요.

네트워크는 **소유자만 볼 수 있도록 잠겨 있지 않아요**. 누가 설치했든 서버의 모든 컴퓨터에서 그 서버의 모든 네트워크를 볼 수 있어요.
