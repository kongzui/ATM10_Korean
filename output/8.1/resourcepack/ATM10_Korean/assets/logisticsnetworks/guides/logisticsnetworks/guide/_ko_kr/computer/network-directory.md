# 네트워크 목록

컴퓨터 화면의 왼쪽 패널이에요. 서버의 모든 네트워크를 보여 주며 연결할 네트워크를 선택할 수 있어요.

![네트워크 관리자에서 네트워크 네 개를 보여 주는 목록](../computer/images/network-manager-idle.png)

## 목록에 표시되는 정보

각 항목에는 **네트워크 이름**(기본 이름은 `Network`이며, 다른 이름이면 누군가 바꾼 거예요)과 **노드 수**가 표시돼요. 고정된 네트워크는 항목 오른쪽 위의 별이 밝고, 고정하지 않은 항목은 어두워요.

![별로 고정하고 현재 선택한 네트워크 항목의 상세 모습](../computer/images/network-entry.png)

- 이름 옆의 `>` 표시는 항목이 **선택되었다**는 뜻이에요. 아직 연결되지 않고 강조된 상태예요. 한 번 더 누르거나 "RUN"을 누르거나 두 번 클릭하면 연결돼요.
- 노란색으로 채워진 별은 고정된 네트워크라는 뜻이에요. 아래를 참고하세요.

## 검색

목록 위의 입력란은 네트워크 이름에 입력한 문자열이 포함되는지로 목록을 걸러요. 최대 32자이며 대소문자는 구분하지 않아요. 입력란을 비우면 모든 네트워크가 다시 보여요.

## 페이지 이동

한 페이지에는 항목 4개가 들어가요. 아래의 `1-4 / 16`은 현재 표시 범위와 전체 네트워크 수예요. 목록 위에서 마우스 휠을 굴리면 나머지 페이지로 이동해요.

## 고정하기 (즐겨찾는 네트워크)

항목 오른쪽 끝의 **별** 아이콘을 누르면 고정 여부가 바뀌어요. 고정된 네트워크는 목록 맨 위에 표시돼요. 네트워크가 많지만 자주 사용하는 것이 몇 개뿐일 때 편리해요.

고정 상태는 플레이어나 네트워크가 아니라 컴퓨터 블록에 저장돼요. 컴퓨터마다 다르게 고정할 수 있고, 블록을 부수면 고정 상태가 초기화돼요.

## 세션 대기 패널

네트워크에 연결하기 전에는 오른쪽에 세 가지 키보드 힌트가 있는 작은 도움말이 표시돼요.

- **DIR** — 네트워크 탐색. 현재 보고 있는 목록이에요.
- **TAB** — 세션 선택. 연결한 뒤 입출력 모니터와 노드 표 중 하나를 골라요.
- **RUN** — 하위 시스템 열기. 선택한 하위 시스템으로 이동해요.

패널에는 전체 네트워크 수(스크린샷의 `16 NETWORKS`)와 진행 단계에 따라 켜지는 상태 표시등(`IDLE` / `READY`)도 있어요.

## 네트워크 연결하기

항목을 한 번 눌러 선택한 다음 **RUN**을 누르거나 항목을 다시 누르면 연결돼요. 대기 안내가 사라지고 하위 시스템 버튼이 활성화돼요. 여기에서 [입출력 모니터](io-monitor.md)나 [노드 표](node-table.md)를 열 수 있어요.

네트워크를 바꾸려면 하위 시스템 화면의 **나가기**를 눌러 목록으로 돌아온 뒤 다른 항목을 고르세요.
