# 입출력 모니터

연결한 네트워크의 실시간 측정 화면이에요. 네트워크 전체의 활성 채널을 채널 번호별로 합쳐 보여 주며, 각 채널을 열어 전송량 그래프를 볼 수 있어요.

연결한 네트워크의 하위 시스템 버튼으로 여세요. 왼쪽 위의 **나가기**를 누르면 목록으로 돌아가요.

## 채널 목록

![입출력 모니터 채널 목록 — CH0(아이템)과 CH1(유체) 표시](../computer/images/io-monitor-channels.png)

각 행은 이 네트워크에서 노드 하나 이상이 사용 중인 채널 번호를 나타내요.

- **CH0** / **CH1** / ... — 채널 번호예요(0부터 8까지). 노드 화면의 채널 슬롯 번호에 해당해요.
- **유형** — **아이템**, **유체**, **에너지**, **화학 물질**, **마나** 중 무엇을 옮기는지 표시하며 유형별 색상이 있어요.
- **노드 수** — 네트워크에서 이 채널을 켠 노드 수예요.

각 행 왼쪽에는 채널 유형에 맞는 **색상 막대**가 있어요. 아이템은 초록색, 유체는 파란색 등이므로 오른쪽 글자를 읽지 않고도 유형을 알아보기 쉬워요.

집계는 **노드별이 아니라 채널 번호별**이에요. 노드 10개가 모두 CH0에서 아이템을 전송하면 10개 행 대신 `CH0 Items 10 nodes` 한 행이 표시돼요. 행을 누르면 그래프가 열려요.

## 전송량 그래프

![입출력 모니터 전송량 그래프 — 최고 약 200K/s인 CH0 실시간 막대](../computer/images/io-monitor-graph.png)

채널 행을 누르면 해당 채널의 **시간별 실시간 전송량** 그래프가 열려요.

- 총 **120개의 측정값**이 있어요. 막대 하나가 측정값 하나이며, 맨 오른쪽이 최신 값이에요.
- 측정 데이터가 들어오면서 대략 매초 갱신돼요.
- 눈금은 최고값에 맞춰 바뀌어요. 위쪽에는 유형에 맞는 단위와 함께 최고값(예: `200.0K /s`)이 표시돼요.
  - **아이템** — 초당 아이템 수.
  - **유체** — 초당 밀리버킷(`mB/s`).
  - **에너지** — 초당 Forge Energy / RF.
  - **화학 물질** — 초당 밀리버킷.
  - **마나** — 초당 마나.
- 새 데이터가 들어오면 왼쪽 아래의 **실시간** 표시등이 켜져요.

## 그래프 읽기

- 높은 막대가 일정하게 이어짐 = 전송량이 일정하며 설비가 활발하게 작동 중이에요.
- 빈 그래프 = 채널은 있지만 전송이 이루어지지 않아요. 필터, 상태, 공급 블록에 실제 자원이 있는지 확인하세요.
- 막대가 간헐적으로 솟음 = 자원을 몰아서 전송해요. 지연이 큰 채널이나 간헐적으로 생산하는 설비에서 흔해요.
- 갑자기 영으로 떨어짐 = 채널이 멈췄어요. 공급처 소진, 레드스톤에 의한 정지, 노드의 네트워크 연결 해제 등이 원인이에요.

그래프 화면의 **나가기**를 누르면 채널 목록으로 돌아가요.
