# 렌치

렌치는 노드 설정 열기, 제거, 노드 사이의 설정 복사, 여러 노드의 대량 설치 등 노드와 관련된 모든 작업에 사용하는 도구예요.

서로 다른 기능을 가진 세 가지 모드가 있어요. 렌치를 든 상태에서 **Shift + 마우스 휠**로 모드를 전환하세요. 현재 모드는 화면 위쪽의 HUD에 표시돼요.

## 모드 한눈에 보기

- [렌치](wrench-mode.md) — 기본 모드예요. 노드 설정을 열거나 노드를 제거하며, AE2가 설치되어 있으면 AE2 연결을 전환해요.
- [복사/붙여넣기](copy-paste.md) — 노드의 채널, 필터, 업그레이드, 이름표를 포함한 전체 설정을 다른 노드에 복사해요. 같은 종류의 연결된 블록에 있는 모든 노드에 한꺼번에 붙여넣을 수도 있어요.
- [대량 설치](mass-placement.md) — 여러 블록을 선택한 뒤 한 번의 클릭으로 모두에게 설정된 노드를 설치해요.

## 조작 요약

| 모드 | 우클릭 | Shift + 우클릭 | Ctrl + 우클릭 |
|------|-------------|---------------------|--------------------|
| 렌치 | 노드 설정 열기 | 노드 제거 (또는 AE2 연결 전환) | — |
| 복사/붙여넣기 | 노드 → 클립보드 복사 (허공에서는 클립보드 편집기 열기) | 클립보드 → 노드 붙여넣기 | 같은 종류의 연결된 블록에 있는 모든 노드에 붙여넣기 |
| 대량 설치 | 블록 선택 전환 (허공에서는 설치 메뉴 열기) | 우클릭과 같음 | 같은 종류의 연결된 블록을 한꺼번에 선택 |

## 렌치와 이름표 함께 사용하기

이름표는 렌치와 함께 사용하면 편리해요. 노드에 설정을 붙여넣으면 원본의 이름표도 복사되므로, 대상 노드는 즉시 해당 이름표 그룹에 들어가 같은 이름표의 다른 모든 노드와 설정을 동기화해요.

일반적인 사용 순서예요.

1. 노드 하나에 원하는 설정을 하세요.
2. 이름표를 지정하세요. [상단 영역 → 이름표 설정](../nodes/header.md)을 참고하세요.
3. 렌치 클립보드에 설정을 복사하세요.
4. 같은 설정을 사용할 다른 모든 노드에 붙여넣거나 대량 설치하세요.

이제 모든 노드에 같은 이름표가 붙어요. 나중에 하나를 편집하면 그룹 전체에 자동 반영되므로, 설정을 바꿀 때 다시 복사해서 붙여넣을 필요가 없어요.
