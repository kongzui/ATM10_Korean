# 석영 섬유

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/assemblies/quartz_fiber.snbt" />
<IsometricCamera yaw="195" pitch="30" />

석영 섬유는 [네트워크](../ae2-mechanics/me-network-connections.md)를 분리한 채 전력을 공유합니다. 에너지 수용기와 전력 케이블을
곳곳에 설치하지 않고도 [서브네트워크](../ae2-mechanics/subnetworks.md)에 전력을 공급할 수 있습니다.
케이블의 연결을 막는 데도 쓸 수 있지만 서로 다른 색의 케이블이나 <ItemLink id="cable_anchor" />를 사용하는 편이 더 저렴하고 효과적입니다.

[케이블 부품](../ae2-mechanics/cable-subparts.md)으로 설치됩니다.
