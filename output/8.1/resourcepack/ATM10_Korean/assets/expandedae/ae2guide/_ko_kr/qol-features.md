# 이 모드는 아래의 모든 편의 기능을 추가합니다
## 패턴 공급기의 패턴 배율 조절: 패턴 공급기에 들어 있는 모든 패턴의 수량을 곱하거나 나누는 버튼을 추가합니다
__배율은 중첩됩니다!__

![패턴 수정](assets/modify_patterns.png)
## 추가 차단 모드: 모든 패턴 공급기에 차단 모드 두 개를 추가합니다
### 기본: AE2의 기본 차단 모드입니다. 연결된 저장소에 이 패턴 공급기의 입력 재료가 하나도 없으면 해당 패턴의 재료를 밀어냅니다. 저장소에 입력 재료가 아닌 아이템이 있어도 무시하고 재료를 밀어냅니다.

![기본 차단 모드 1](assets/blocking/blocking_1.png)

### 전체: 연결된 저장소에 무엇이든 들어 있으면 패턴의 재료를 밀어내지 않습니다.

![전체 차단 모드 2](assets/blocking/blocking_2.png)

### 스마트: 대상 저장소에 특정 패턴의 입력 재료만 있으면 패턴 공급기가 같은 패턴의 재료를 다시 밀어낼 수 있습니다

![스마트 차단 모드 3](assets/blocking/blocking_3.png)
