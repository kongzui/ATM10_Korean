3D 벡터 수학 API의 함수:
vector.new( x,y,z )

vector.new()에서 반환된 벡터에는 다음과 같은 필드와 메서드가 있습니다.
vector.x
vector.y
vector.z
vector:add( vector )
vector:sub( vector )
vector:mul( number )
vector:dot( vector )
vector:cross( vector )
vector:length()
vector:normalize()
vector:round()
vector:tostring()
+, - 및 * 연산자는 벡터에도 사용할 수 있습니다.
