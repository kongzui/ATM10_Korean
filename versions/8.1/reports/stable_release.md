# 보조 번역 제외 안정판 배포 결과

2026-09-08. 현재 배포는 `7.1-stable.1`과 `8.1-stable.1`이에요.
실제 인스턴스는 수정하지 않았고 사용자가 직접 설치해요.

## 변경 범위

AppleSkin 디버그 줄, Mouse Tweaks 설정 화면, EnderDrives 시스템 채팅과 동적 툴팁의 보조
실행 코드를 제거했어요. 버전마다 기존 파일 네 개를 동일 경로의 주석 전용 파일로 교체해요.
ZIP에서 단순히 누락시키는 방식과 달리 기존 설치에 덮어써도 예전 코드가 남지 않아요.
동일 파일명 외에 사용자가 별도 이름으로 복사한 스크립트는 이 전환 검사 범위가 아니에요.

기존 작업 코드는 working과 Git 이력에 보관하며 기본 배포의 재생성 재료로 사용하지 않아요.
규칙과 후속 검토는 `docs/AUXILIARY_TRANSLATION_SCRIPTS.md`에 정리했어요.

파일이 주석만 남는지 검사했고, 실행 시 변수나 이벤트를 등록하지 않는 것도 확인했어요.

## 8.1 원문 검증을 계승한 이유

현재 인스턴스를 다시 검사하니 영어 퀘스트가 `.snbt_merged`로 존재하고 챕터의 이미지 ID,
일부 order_index·item.count 등이 이전 원본과 달랐어요. 원본 경로와 구조의 엄격한 대조는
실패했으며 `current_instance_compat_audit.json`에 그 결과를 보존했어요. 이 차이를 산출물에
반영하거나 실제 게임 파일을 수정하지 않았어요.

이번 배포의 퀘스트·언어·가이드 데이터는 앞서 원문 대조를 통과한 `cfe93e1`의 파일과 바이트
단위로 같아요. 따라서 변경 없는 파일은 이전 원문 검증을 계승하고, 이번 변경인 보조 코드
제거와 메타데이터는 새 안정판 검증기로 확인해요. 이전 원문 검증 보고서와 수정 전 전체
산출물 해시가 서로 일치하는지도 검사해요. 현재 인스턴스와 새 원문 대조까지 통과한 것으로
표현하지 않아요. 원문·번역을 바꾸는 후속 작업은 해당 변경분에 대한 새 검증이 필요해요.

## 배포 및 실제 게임 확인

버전마다 리소스팩 ZIP과 override ZIP을 제공해요. ZIP 내부 목록·CRC·모든 파일 바이트를
output과 대조하고 각 버전의 manifests 폴더와 ZIP 옆 SHA256.json에 결과를 기록해요.
리소스팩은 ZIP 그대로, override는 인스턴스 루트에 병합하고 완전히 재시작해야 해요.

이번 안정판에는 보고된 보조 기능의 실행 코드가 없어요. 실제 Minecraft 실행·플레이를
확인한 것은 아니므로 전체 모드가 항상 정상 작동한다고 보장하지 않아요. 실제 인스턴스,
월드·설정·원본 JAR은 수정하지 않았어요.
보조 기능으로만 번역하던 문구는 원래 표시를 유지하고, 신규 모드 번역은 후속 범위예요.
