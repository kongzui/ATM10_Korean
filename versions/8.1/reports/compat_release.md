# ATM10 8.1-compat.1 배포 결과

후속 게임 실행에서 KubeJS 번역 스크립트 3개의 시작 오류가 확인됐어요. 이 기록은 첫 배포의
정적 검증 결과이며 현재 권장 배포는 `8.1-compat.3`예요. 수정 내용과 실행 검증 범위는
`screen_crash_fix.md`를 확인해요.

완료일: 2026-09-08. 게임 화면 확인은 사용자가 후속 확인으로 보류했어요.

## 배포 파일

`temp/releases/8.1-compat.1/`에 다음 파일을 만들었어요.

| 파일 | 크기 | 내부 파일 | 설치 위치 |
|---|---:|---:|---|
| ATM10_Korean_8.1-compat.1_resourcepack.zip | 4,926,081바이트 | 2,300개 | 8.1의 resourcepacks/ |
| ATM10_Korean_8.1-compat.1_overrides.zip | 6,462,297바이트 | 335개 | 8.1 루트의 config/·kubejs/ |

설치 안내 `INSTALL.md`와 압축 파일의 SHA-256을 담은 `SHA256.json`도 함께 있어요.
리소스팩 ZIP 루트에 `pack.mcmeta`와 `assets/`가 있고, 모든 압축 멤버의 내용이
검증한 output과 일치해요. CRC 검사도 통과했어요. 배포 ZIP은 Git 제외 대상이에요.

## 주요 변경과 재사용

- 7.1 번역값 145,208개를 그대로 유지했어요. 현재 모드 언어는 286개 파일, 147,388개 값이에요.
- 이번에는 모드 언어 누락 111키를 번역하고 기존 값 10키를 고쳤어요.
- 가이드 JSON 2개의 중복 닫기를 제거하고, 원본과 동일한 오류를 통과시키던 검증기를 고쳤어요.
- Modern UI 전용 글꼴 1개를 제외하고 실제 사용하는 글꼴과 출처 안내는 유지했어요.
- Cataclysm·Relics의 낡은 챕터 구조를 8.1 원본에 맞췄어요. 챕터 6개의 한국어
  custom_name 이외 구조가 원본과 같아요. Relics 이미지 제목은 분할 한국어 키로 표시해요.
- PneumaticCraft 가이드 4개를 갱신·추가했고 SFM 후원자 명단도 현재 원문에 맞췄어요.
- 신규 모드 4,779키와 기존 번역의 표현 개선은 후속 누적 업데이트예요.

  구형 검증기를 임의로 8.1 완료 증거로 사용하지 않았어요.
- 제목 감사의 1,098개는 정상 fallback·공식 명칭·기존 표현 불일치가 섞인 후속 검토 후보이며
  실제 오류 수가 아니에요. 완전 신규 번역판으로 표시하지 않아요.

## 남은 확인과 Git

게임 내 리소스팩 목록·JEI·퀘스트·가이드 화면 확인은 사용자가 나중에 진행하기로 했어요.
7.1에서 작동하지 않았다는 피드백의 원인은 당시 실행 로그가 없어 단정하지 않아요.
이번 배포에서 확인한 JSON 오류, 불필요한 글꼴과 ZIP 루트 구조는 해결했어요.

Git 잠금은 사용자의 명시적 제거 지시에 따라 실행 중인 Git이 없는 것을 확인한 뒤
제거했어요. 다음 작업 단위로 커밋했어요.

- `d68b6b3`: 8.1 호환판 우선 배포와 누적 번역 방침 정리
- `ff89825`: 8.1 가이드 JSON 오류와 불필요한 Modern UI 글꼴 정리
- `90ac3da`: 8.1 변경 문구와 퀘스트 구조 호환 번역 보완
- 이 보고서와 배포 검증·패키징 도구는 `8.1 호환판 배포 파일과 검증 결과 확정` 커밋에 포함해요.

재개 시 산출물 2,636개와 ZIP 2개의 해시가 기존 검증본과 같은 것을 확인했어요.
