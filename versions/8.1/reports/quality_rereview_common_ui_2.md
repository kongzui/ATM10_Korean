## 주요 수정 유형

- 새 용어 기준: `개체`→`엔티티`, `재사용 대기시간`→`쿨타임`, `생물군계`→`생물 군계`, `키 설정`→`키 지정`,
  `핫바`→`단축 바`, 바닐라 `위치 표시 바`.
- JourneyMap 표기 통일: Options는 `설정`, 웨이포인트 Label은 `라벨`(바닐라 아이템 `이름표`와 구분),
  Ops는 `OP`, Global은 모드 안의 다수 표기인 `전역`, Pet은 `반려동물`, Mapping은 `지도 작성`.
- 오역·비문: `[%2$s] 키를 눌러 끄기하세요` 같은 비문, 'All' 그룹을 모든 그룹으로 읽히게 한 문장,
  원문에서 빠진 문장, 실제 옵션 이름과 다른 참조, `이는`·`이러한`·`~을 위한` 번역투.
- Waystones: Global은 용어집대로 `전체 공개 웨이스톤`, 쿨타임 명령 결과 문장 정리.
- 구조물: 같은 모드 안에서 크기 표기(큰·작은 또는 대형·중형·소형)와 CTOV의 `(대형)` 접미 형식을
  맞추고, 바닐라 표기 `정글나무`로 통일.

## 분업 시험 운영 평가

| 항목 | 결과 |
|---|---|
| 워커 구성 | Sonnet 워커 2개 병렬(A: JourneyMap, B: 나머지 4개), 공통 지시문 사용 |
| 워커 사용량 | A 약 23만 토큰·5분, B 약 21만 토큰·5.5분 |
| 워커 수정 | A 110키, B 59키. 모두 사유를 달아 제출 |
| 오케스트레이터 검토 | 수정 169키 전수 검토, 유지 키 60개 무작위 표본 검토, 번역투 패턴 검사 |
| 되돌림·보정 | 워커 수정 중 2키(문장이 아닌 형태로 바뀐 명령 결과) 보정, 0키 되돌림 |
| 워커가 놓친 항목 | JourneyMap 8키(`이는`·`이러한`·`이 옵션을` 번역투, 안내문 말투)를 오케스트레이터가 추가 수정 |
| 형식 오류 | 0건(검증 스크립트 통과 후 제출) |
| 지시 위반 | 워커 A가 읽기 전용 `git status`를 한 번 실행(쓰기·커밋 없음) |

판단: 워커 수정의 정확도는 높고(되돌림 0), 놓친 번역투는 패턴 검사와 표본 검토로 대부분 잡혀요.
3순위부터 같은 방식을 쓰되, 지시문에 번역투 자가 점검 패턴 목록과 "git 명령 전면 금지"를 더 분명히
적어요.
