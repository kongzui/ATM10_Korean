# 7.1·8.1 KubeJS 오류 수정 배포

2026-09-08. 배포 이름은 `7.1-final.1`과 `8.1-compat.2`예요.

## 확인한 원인과 수정

사용자의 8.1 실행 로그에서 AppleSkin·EnderDrives·Mouse Tweaks의 블록 내 const 선언이
재선언 오류를 일으켰어요. 7.1의 Rhino 2101.2.7-build.81과 8.1의 2101.2.8-build.91에서
기존 스크립트 3개씩 같은 오류를 직접 재현했어요. Node.js 문법 검사로는 발견되지 않았어요.

const를 let으로 바꾸고 번역·수치·색상·정규식·이벤트 우선순위는 그대로 유지했어요.
콜백 실행 검사에서 Mouse Tweaks의 블록 내 함수 선언도 undefined가 되는 문제가 확인돼
`let translateWidgets = function (...)`으로 바꿨어요. 초기화 통과만으로 완료 처리하지 않았어요.

사용자의 명시적 요청으로 7.1에도 같은 스크립트 수정, Herbs and Harvest 가이드 2개의
중복 닫기 제거와 개인 Modern UI 글꼴 제외를 반영했어요. 8.1의 번역·퀘스트를 7.1에 이식하지 않았어요.

## 검증 결과

| 항목 | 7.1-final.1 | 8.1-compat.2 |
|---|---:|---:|
| 변경 없는 모드 언어 값 | 145,570 | 147,388 |
| 새 번역 | 0 | 0 |
| JSON·메타데이터 문법 | 1,760 | 1,761 |
| SNBT 문법 | 7 | 76 |
| JavaScript 문법 | 24 | 27 |
| 실제 Rhino에서 기존 오류 재현 | 3 | 3 |
| 수정본 실행 조건 검사 | 3 | 3 |
| 글꼴 참조 | 3 | 3 |

실행 조건은 클라이언트·서버·관련 모드 미설치예요. 클라이언트에서는 F3 표시의 반복 갱신,
설정 화면 초기화와 반복 렌더, 채팅 반복 번역, 무관한 문구·화면·아이템 필터를 검사했어요.
실제 Rhino 엔진을 사용했고 Java·Minecraft API는 대역이므로 실제 게임 화면과 NeoForge
이벤트 연결까지 확인했다는 의미는 아니에요. 수정판의 게임 내 재확인은 남아 있어요.

Git 기준 커밋 `18eb59d`와 전체 산출물을 대조해 선언 호환성·가이드 문법·개인 글꼴·배포
메타데이터 외 변경을 차단했어요. 기존 world/ Git 제외 규칙에 걸린 가이드 10개는 이전
배포의 해시와 양 버전 원문이 같다는 검토 기록으로 확인했어요. 이 가이드들도 ZIP에 포함해요.
이번 수정에서는 FTB Quests와 나머지 KubeJS 내용을 변경하지 않았어요.

각 버전의 `startup_hotfix_validation.json`에 전체 산출물 해시와 실제 엔진 검사 결과가 있어요.
8.1은 `compat_validation.json`의 원문·번역 키·자리표시자·구조 검사도 다시 통과했어요.
ZIP 네 개의 CRC와 모든 내부 바이트가 검증본과 일치해요.

| 배포 | 리소스팩 ZIP | override ZIP |
|---|---|---|
| 7.1-final.1 | 4,880,013바이트 / 2,299파일 | 6,410,439바이트 / 263파일 |
| 8.1-compat.2 | 4,926,072바이트 / 2,300파일 | 6,462,282바이트 / 335파일 |

## 설치와 적용 상태

사용자가 직접 설치하기로 했으므로 실제 7.1·8.1 인스턴스에 쓰기 작업을 하지 않았어요.
원본 JAR은 읽기만 했고 수정하지 않았어요. 월드·설정·리소스팩 선택도 변경하지 않았어요.

버전별 `temp/releases/<배포 이름>/`에 리소스팩·override ZIP, INSTALL.md와 SHA256.json을
제공해요. 리소스팩은 ZIP 그대로 활성화하고 override는 해당 버전 루트에 병합해요.
기존 팩은 비활성화하고 Minecraft를 완전히 다시 실행해야 해요.

이번에는 기존 번역의 실행 오류를 수정했어요. 8.1 신규 모드 4,779키와 기존 표현 검토는
이전 계획대로 후속 업데이트 범위예요.
