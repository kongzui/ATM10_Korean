# Logistics Networks 일반 언어 검수

현재 설치된 `logisticsnetworks-1.21.1-1.13.0.jar`의 영어 454키를
150·150·154개 내부 단위로 대조했어요. 현재 JAR에 한국어는 없어요.

- 신규 번역 434개, 기존 한국어 재사용 0개, 원문 유지 20개예요.
- 원문 유지는 공식 모드명, 단위, 좌표·페이지 자리표시자, 입력 예시 ID와 정보 아이콘이에요.
- Sender/Receiver는 송신/수신, Batch는 전송량, Ars Source는 용어집의 마나로 통일했어요.
- 이름·컴퓨터·렌치·노드·필터·설정·발전 과제·단축키의 모든 언어 값을 검수했어요.
- JSON 중복 키·자료형·454키 일치·자리표시자·숫자·서식·개행 검사를 통과했어요.
- 검증 중 실제 인스턴스의 파일 경로·크기·수정 시각이 유지됐어요.

이 커밋은 일반 언어 단위예요. GuideME 17페이지와 별도 가이드 등록 파일,
FTB Quests·KubeJS 연관 조사, 누적 배포 및 실제 게임 적용은 다음 단위에서 진행해요.
게임 화면의 실제 표시 검증과는 구분해요.
