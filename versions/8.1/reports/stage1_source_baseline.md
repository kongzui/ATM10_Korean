# 단계 0 보완 · 단계 1 원문 기준

조사일: 2026-09-09. 단계 1 대상은 Auroral과 Neo Vitae예요.
현재 인스턴스는 읽기 전용으로 사용하고 사용자가 ZIP을 직접 설치해요.

## 설치 모드

`versions/8.1/manifests/jar_inventory.csv`의 488개와 현재 설치 JAR의 이름·크기가 모두 같아요.
팩 manifest와 CurseForge 설치 메타데이터를 대조하면 487개는 팩 지정 파일이고,
`cc-tweaked-1.21.1-forge-1.120.2.jar` 하나는 팩의 overrides로 제공된 파일이에요.
설치 메타데이터의 `/overrides/mods/` 목록으로 확인했으며 개인 추가 모드로 세지 않아요.
전체 JAR의 이름·크기 비교와 이번 번역 대상 JAR의 SHA-256 검증은 구분해요.

- Auroral: `auroral-1.21.1-1.1.1.jar`, 영어 148키, 내장 한국어 후보 0키
- Neo Vitae: `neovitae-1.21.1-1.1.15.jar`, 영어 3,053키, 내장 한국어 후보 0키

## 퀘스트 원문 선택

현재 분할 영어 70개 파일의 8,922키는 최초 8.1 `ftbquests_english_hashes.json`과
키별 값 해시가 모두 같아요. 신규·변경·누락은 각각 0키예요.
실행 후 파일 이름이 `.snbt_merged`로 바뀐 상태이며, 파일 이름만으로 원본이라고 가정하지 않고
내용 해시가 일치하는 분할 영어를 번역 기준으로 선택해요.

최상위 병합 영어는 8,932키예요. 분할본에만 있는 29키와 병합본에만 있는 39키가 있고,
공통 키의 값 변경은 없어요. 주로 빈 이미지 제목과 실행 중 생성된 이미지 ID예요.
최상위 병합 파일을 분할 원문의 대체 자료로 사용하지 않아요.

경우에만 이전 검증을 계승하고, Auroral·Neo Vitae의 변경 언어 파일은 별도로 현재 원문을 검사해요.

## 가이드와 배포 검증 경계

Auroral에는 일반 언어와 별개인 GuideME Markdown 29페이지가 있어요.
Neo Vitae의 Modonomicon 가이드 223개 JSON은 언어 키 1,529개를 참조해요.
일반 언어 키 수와 가이드 페이지·참조 키 수를 중복 합산하지 않아요.

누적 안정판 검증은 `3aa66388e4cf3fcf9dc1f928d90dedc250769d5e`의 stable.1을 기준으로
변경하지 않은 파일만 해시로 계승해요. 변경 파일은 현재 JAR·퀘스트 원문, 검수 기록,
보호 문자열과 표시 경로 검증을 통과해야 해요. 전체 파일의 문법·보조 코드 제외·ZIP 검사도 유지해요.
검수 해시만 바꾸어 신규 번역 검사를 우회하지 않아요.

이는 파일과 코드의 정적 검증이에요. 실제 게임 화면 확인은 사용자 설치 후 별도 기록해요.

원본 보호 비교에는 저장소 내부 `temp/stage1_before.json`을 사용해요.
